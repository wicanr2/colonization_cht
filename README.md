# 《殖民帝國》中文高清版（Remastered）

讓繁體中文玩家能直接讀懂《Sid Meier's Colonization》（1994），並以精細像素風呈現原版畫面。遊戲規則、操作與存檔格式沿用原版。

## 已完成的內容

- 中文顯示：選單、對話、教學、百科、殖民地、歐洲港口、報告與事件標題。
- 高清文字：四地區 Noto 字型，提供繁中、簡中、日文、韓文及英文的顯示切換。
- HD 圖像：地形、建築、商品與資源小圖、單位、人物及頭像、游標、背景、邊框與事件插圖。
- HD 動畫接線：片頭船隻、太陽、雲、煙、魚形、16 幀 MPS 旋轉標誌，以及已收錄的片尾人物、道具與煙火影格。播放時序沿用原版。
- 顯示設定：語言與原版／HD 圖像獨立切換，設定期間暫停遊戲。HD 事件標題使用金色文字。

目前已完成已知來源的接線，以及 Linux、Windows、macOS 的兩類本機完整版。推廣影片包含新局航海、登陸、建立第一座城鎮與 HD 城鎮操作；剩餘畫面由人工驗證。未辨識或未確認的情境會保留原文、原圖；尚未宣稱全遊戲中文與 HD 都已驗收。

完整版固定分成「HD＋原版＋中文化」與「原版＋中文化」兩類，兩包都保留 Noto 文字。現行版本與使用入口見[交付說明](CONTEXT.md)。[公開下載](https://github.com/wicanr2/colonization_cht/releases/tag/v.1.0.3-20261010)仍為較早的繁中功能包，尚不含最新 HD 整合內容。
