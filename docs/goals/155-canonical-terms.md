# 目標155：定稿譯名（Issue #27 第二輪）

狀態：完成；開始與完成：2026-09-26。對應 [Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)，接續[目標154](154-manual-glossary.md)。

## 範圍

- 從 `text/glossary.zh-Hant.tsv` 為核心遊戲名詞各定一個譯名，寫入 `text/terms.zh-Hant.tsv`：單位、職業／專家、建築、貨物、地形、船、建國之父、原住民族、國家，以及遊戲畫面上會出現的概念詞（自由鐘、十字架、自由子民、保皇黨、皇家遠征軍等）。
- 取捨規則（依使用者「第三波說明書優先」決定）：說明書有印出對照者優先；同一英文多個譯名時，取定義該項目的章節或參考卡的譯名，其次取出現最多者；描述性譯法（「……鈕」「……選單」、解釋句）不當譯名；說明書沒有而譯稿已有者沿用譯稿並標示「非說明書」。
- 本輪只定譯名與規則，不改譯稿。

## 退出條件

- 每筆定稿有英文、譯名、類別、出處影像、其他譯名與取捨理由。
- `tools/check_glossary.py` 可改用定稿表重跑，得出逐列改稿清單。

## 使用者決定（2026-09-26）

- 說明書明顯錯字與誤譯：修正後採用，定稿表記下說明書原寫法（斥候、輕刑罪犯、Mission＝傳教所、Rum Factory＝甜酒廠）。
- 國名：改用說明書「英國／法國／西班牙／荷蘭」，畫面上的形容詞形 English／French／Spanish／Dutch 同樣譯法。已上線的旗卡與海上欄位要改稿重驗。
- 同一英文多個譯名：參考卡與圖表優先（沼池、蔗糖、槍、老手）。
- 人名：照說明書連寫，不加間隔號。
