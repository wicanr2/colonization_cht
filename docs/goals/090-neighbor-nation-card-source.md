# 目標090：相鄰旗卡紅字的原版來源與畫布輸出鏈

狀態：進行中；日期：2026-09-24。承接
[目標089](089-first-nation-card-runtime-guard-evidence.md)及
[規格021](../spec/021-nation-card-red-text-draft.md)；對應
[Issue #7](https://github.com/wicanr2/colonization_cht/issues/7)、
[Issue #12](https://github.com/wicanr2/colonization_cht/issues/12)與
[Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)。

## 玩家問題與範圍

正常左鍵點國家頁右上相鄰旗卡 `(255,50)` 後，第一張旗卡的上、下
紅字畫布區域重繪。這足以要求舊補片失效，卻還不知道新畫面究竟
印了哪兩則文字，或它們來自哪個原始檔案位址。本輪只閉合這個
相鄰旗卡的「原始位元組 → 原版 RAM／格式化字串 → 印字事件 →
畫布」證據鏈；不依旗幟圖案、常識國名或同文搜尋直接猜來源。

## 執行與退出條件

1. 先推送本目標。固定合法 DOS 原版檔案指紋、隔離 dosgolem、
   已驗16筆正常玩家輸入與目標089的左鍵／控制收據。全部分析、
   探針、測試只在限資源 Docker；原版唯讀，原版像素與 RAM 報告
   只留 `workplace/`。
2. 於右上旗卡切換前後，取得上、下紅字印字前後的原版畫布與
   `CS:IP` 讀字／寫畫布事件，核對差分點數、bbox、色號、字串
   格式化結果。先排除只是舊字清除或旗面換圖的誤判。
3. 對兩處新字各自追來源：原始檔名與 SHA-256、檔案位元組偏移、
   DOS 讀取、RAM 整理／常駐／格式化流向與實際畫布消費者。
   若資料鏈只閉合一段，按證據等級記錄並保持 DRAFT，不憑文字
   相同升格為正式鍵。
4. 至少雙次獨立冷啟動及一組無監看控制，比較 CPU、完整 RAM、
   索引畫面、色盤、虛擬時間、開檔與當次畫布。建立獨立驗證器；
   僅在來源閉合時新增可追溯繁中**草稿**，並驗原始片段與字形。
5. 更新研究紀錄、規格021或獨立 DRAFT、`CONTEXT.md`、唯一
   工作清單及 `WORKLOG.md`；推送私有 repo 並回填對應 Issue。
   收尾檢查原版素材未入 Git、檔案擁有權與 Docker 容器清理。

## 停止線

本輪不代替使用者在第一張旗卡 A／B 版式間定案，不接正式前端、
不更新成果截圖或十四段已驗中文數。右上旗卡以外的旗卡、help、
選國規則與完整遊玩不因這條來源鏈而宣稱完成。
