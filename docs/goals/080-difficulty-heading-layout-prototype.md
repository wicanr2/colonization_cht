# 目標080：難度畫面標題的原版階層與逐欄字級預覽

狀態：量測與可丟棄原型完成，等待使用者選版；日期：2026-09-23。承接[目標079](079-first-card-formal-overlay.md)、
[規格014](../spec/014-difficulty-text-output-draft.md)及
[Issue #28](https://github.com/wicanr2/colonization_cht/issues/28)。

## 問題與範圍

使用者指出目前私有難度頁截圖的「選擇／難度」兩行排版不符原版風格，且
中文字級應依畫面與欄位調整，不得共用全域常數。本輪先用同狀態英文控制
畫面與原始印字證據量測標題的兩層文字階層，再產出可丟棄的並列預覽；
不把視覺候選直接當成使用者決定，也不修改已驗收的正式輸出。

## 工作與退出條件

1. 固定合法 DOS 版本、九筆正常玩家輸入、dosgolem 與 Ebitengine 版本；
   對原版 `Choose`／`Difficulty Level` 逐行記錄來源事件、墨跡 bbox、
   字高、中心、行距、色號與半開安全矩形。確認游標及卡片不與標題區混淆。
2. 依原版兩行的相對大小與對齊，分別量測「選擇」「難度」的候選字級、
   墨跡、頂列與內距；同頁卡片稱號／副標、完成提示只核對各自既有字級及
   畫面階層，不以標題候選字級覆蓋其他欄位。
3. 以同一原始索引畫面及可逆背景補片，產生英文控制、目前中文、至少兩個
   不同標題排版候選的本機對照圖；逐像素確認候選只在已證實的標題安全區
   改變，原版 CPU／RAM／索引畫面不被預覽修改。預覽圖含原版像素，只留
   已忽略的 `workplace/reports/`，不加入 Git 或公開雲端。
4. 在 DRAFT 規格及研究紀錄標示已證實的原版幾何、候選字級與仍待使用者
   判斷的視覺取捨；提供清楚的並列成果請使用者選擇。取得確認之前，
   不修改正式 `tools/live_menu.go`、既有私有截圖或標記 Issue #28 完成。
5. 更新 `CONTEXT.md`、`RESEARCH-LOG.md`、`WORKLOG.md`、工作清單與
   Issue #28；核對 Git 權利邊界及 Docker 清理狀態，推送私有儲存庫。

## 停止線

不改原版 EXE、TXT、圖像、存檔、規則或滑鼠命中區。原版標題的墨跡頂列
不自動等同字型 baseline；無證據不得聲稱精確字型或全畫面字級等價。
Issue #28 的正式完成條件是使用者確認版式後再經 READY、實作與正常玩家
路徑驗收，本輪原型本身不關閉它，也不把十段中文顯示計數增加。

## 本輪結果

原版兩行墨跡中心同為四倍畫布 x=230、高度分別32／36px；目前中文
24／24px沿英文各自左起點放置，因此兩行相互錯開。[規格018草案](../spec/018-difficulty-heading-layout-draft.md)
保存原始 bbox、安全矩形、逐欄候選字級、Ebitengine 本機對照及停止線。
候選 A 將34／38px兩行置於同一中心線；候選 B 保留左起點但分別放大。
四格 PNG 只在本機 `workplace/reports/goal080-heading-preview/comparison.png`，
不加入版控。逐像素驗證只改兩個標題安全區；正式畫面、原版素材及已驗收
十段中文數均未改動。下一步待使用者看圖選擇，再啟動 READY 與正式接線。
