# 目標075：追上難度卡片原文到畫布的直接路徑

狀態：completed（證據切片；中文覆蓋仍未就緒）；日期：2026-09-23。對應 Issue [#6](https://github.com/wicanr2/colonization_cht/issues/6)、[#7](https://github.com/wicanr2/colonization_cht/issues/7) 與 [#26](https://github.com/wicanr2/colonization_cht/issues/26)。

## 起點與範圍

[目標074](074-difficulty-card-observation-repair.md)已在兩次正常玩家路徑確認第一張難度卡片的
`Discoverer`／`Easiest` 原文字節讀取，及後續 `0D21:012C` 的292次卡片畫布寫入。
然而「前後發生」仍不等於「同一條資料流」。[規格016](../spec/016-difficulty-card-text-draft.md)
仍是 DRAFT，卡片維持英文。

本輪以原版唯讀輸入和 dosgolem 的窄時間窗觀測，追查 `0E2D:11CF` 來源讀取、暫存緩衝、
字形產生及 `0D21:012C` 畫布寫入間的邊。先追第一張卡片兩行；若正常玩家輸入能安全切卡，
再以第二張卡片作反向條件。只在證據足以建立欄位守門、原版字高／基線與可逆背景後，
才討論升 READY 或製作可丟棄中文原型。本輪不修改原版遊戲或正式覆蓋。

## 工作與退出條件

1. 建立有固定原版 SHA、dosgolem 版本、輸入雜湊及地址空間的窄時間窗探針；
   捕捉兩段原文讀取時的 CPU 暫存器、指令位元組、堆疊，以及同一步／近鄰記憶體寫入。
   觀測器不得更改原版狀態；兩次結果及舊最終 RAM／畫布／色盤須一致。
2. 將候選暫存緩衝追至可核對的輸出事件；在原始畫布分開量測兩行墨跡範圍、字高與基線，
   不以兩行合併的 bbox 或既有24px中文常數外推。若直接鏈未閉合，記錄第一個未知邊。
3. 依證據分級更新規格016；若無法證明兩行各自來源、守門、背景與欄位安全矩形，
   明確維持 DRAFT 與原文回退。新增中文字級前須依該欄原文字高及放大畫布實測。
4. Docker 內完成重播／回歸與清理；原版、記憶體 dump、截圖只留本機。
   完成後更新本目標、研究紀錄、工作清單、私有儲存庫及相關 Issue。

## 停止線

不把卡片輸出推論升格為正式文字鍵；不靠修改難度規則、輸入或存檔來造出卡片畫面。
遇到缺少的 dosgolem 通用觀測能力，先留最小重現與 DRAFT，不在本遊戲程式碼中模擬原版流程。

  記憶體寫入、CPU 指令位置／暫存器與兩行畫布前後快照；未改任何遊戲狀態。
