# 目標156：譯稿套用定稿譯名（Issue #27 第三輪）

狀態：進行中；開始：2026-09-26。對應 [Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)，依[目標155](155-canonical-terms.md)的定稿表。

## 範圍

- 目標155 列出的 229 列逐列改稿：只把術語換成定稿譯名，句意與其他文字盡量不動。英文原文裡同形但非術語的用法（例如動詞 turn）可不換，須寫理由。
- 流程：切批 → 共用指令檔（定稿表＋硬規則）→ 子代理平行改稿 → 合併時逐列驗證（鍵不變、ASCII 片段與占位符不變、應換術語已出現或有不換理由）→ 重跑術語檢查。
- 已驗收的正式欄位（主譯稿、旗卡片段、海上欄、字幕變數、國家介紹）若譯文改變，重烘字模並重跑對應驗證與全面回歸。

## 退出條件

- 術語檢查只剩有理由的不換列。
- 受影響正式欄位的驗證與全面回歸 PASS；驗證矩陣重跑 PASS。
