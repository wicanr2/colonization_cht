# 目標064：先完成可追溯譯文語料

狀態：in_progress；日期：2026-09-22。對應 Issue [#7](https://github.com/wicanr2/colonization_cht/issues/7)、[#10](https://github.com/wicanr2/colonization_cht/issues/10)、[#27](https://github.com/wicanr2/colonization_cht/issues/27)。

## 使用者優先順序

先把可辨識的玩家可見原文翻成繁體中文，再逐段處理 dosgolem 輸出掛鉤。
譯文完成與畫面驗收是兩種不同狀態；本目標不把未命中的譯稿算成已中文化畫面。

## 已知分母與缺口

主譯稿 `text/draft.zh-Hant.tsv` 有189筆，help雙語稿
`text/help-bilingual.tsv` 有24則，兩者目前都沒有空白繁中欄。
唯讀盤點找到18份 `*.TXT` 與4,119個粗略資料行；這些行混有控制資料、
非玩家內容、跨行訊息，也沒有計入EXE及靜態圖像文字，不能當成完整訊息分母。
現有主譯稿僅涵蓋 `GAME`、`LABELS`、`MENU`、`NAMES`、`PEDIA` 的部分來源；
help稿僅涵蓋 `GAME` 教學19則與 `MAPEDIT` 說明5則。

## 工作順序與退出條件

1. 以固定原版雜湊建立逐檔、逐章節的文字分類清冊：玩家可見、控制資料、
   重複來源、未知；每筆保留檔案位移與原始片段指紋。不能用「粗略資料行」
   直接生成千筆看似完整的譯文。
2. 優先處理選單、難度、遊戲訊息、百科及說明，再審查其他TXT與EXE／圖像
   可見文字。每批譯文進唯一UTF-8 TSV來源，明示草稿／已審校／畫面已驗收，
   不讓兩份TSV對同一執行期訊息互相競爭。
3. 每批重跑原始檔SHA、片段SHA、鍵唯一、占位符／控制碼、UTF-8及字型覆蓋
   驗證；術語有歧義時保留草稿狀態並列待決，不以猜測補足原版語意。
4. 完成聲明必須列出已分類的玩家可見訊息分母、已譯、待審校、未譯、
   執行期命中與畫面驗收數；EXE及靜態圖像若尚未盤點，不能聲稱「全文翻譯完成」。

原版輸入、畫面與圖像只在本機唯讀使用；原文是否能公開仍未知，
本輪譯稿只可進已核對為私有的儲存庫。
