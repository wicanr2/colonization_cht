# 目標087：第一張國家旗卡紅字的檔案載入邊

狀態：完成（限定來源鏈與 DRAFT）；日期：2026-09-23。承接[目標085](085-nation-card-text-provenance.md)
的當次動態印字證據；對應[Issue #7](https://github.com/wicanr2/colonization_cht/issues/7)
與[Issue #12](https://github.com/wicanr2/colonization_cht/issues/12)。

## 問題與界線

第一張旗卡上、下紅字已證實由原版印字事件形成，但
`NAMES.TXT:0x8EA`／`LABELS.TXT:0x8F2` 尚只是內容相符的檔案候選。
本輪追查原始檔案位移到 DOS 讀取緩衝、執行期來源緩衝、格式化
緩衝及畫布寫入的完整資料鏈。只研究已在正常玩家路徑可見的
兩處文字，不修改正式中文覆蓋、原版程式、資料、規則或存檔。

## 執行與退出條件

1. 先推送本目標至確認為 PRIVATE 的儲存庫。固定原版檔案 SHA-256、
   隔離 dosgolem 提交、原始16筆真視窗輸入及50M步終點；原版
   唯讀掛載，所有探針、建置與驗證只在有界 Docker 容器。
2. 以 dosgolem 觀測原版 DOS 檔案開啟／讀取與 RAM 寫入，逐筆標明
   handle、檔案位移、讀取長度、目的線性位址、原始位元組及時間。
   對 `NAMES.TXT:0x8EA`／`LABELS.TXT:0x8F2` 分開驗證，不因
   字串內容相同就假定是同一來源。
3. 從讀取緩衝追到 `0x2A74A` 來源候選及 `0x2A6AE` 格式化緩衝，
   保留原始 `CS:IP`、操作數、20-bit 線性 RAM 與檔案位移的不同
   位址空間。檢查寫入者、讀取者與時間順序；需要時用相鄰旗卡
   或相鄰字串作負例。不能閉合的邊維持強推論或未知。
4. 至少兩次獨立冷啟動及同輸入無觀測控制，比對 CPU、完整 RAM、
   原版索引畫面、色盤、虛擬時間與開檔序列；建立獨立驗證腳本
   和只留在 `workplace/` 的收據。原版缺失時明確 skip。
5. 若完整來源鏈與負例足夠，完成目標085並建立**僅 DRAFT** 的
   第一張旗卡兩欄規格，列出下一輪 READY 仍須的背景、游標、
   逐欄字級／安全矩形與失敗回退證據；不足則記錄精確缺口，
   不把候選鍵寫入正式程式。
6. 更新 `CONTEXT.md`、`RESEARCH-LOG.md`、`WORKLOG.md`、唯一工作
   清單及對應 Issue，推送私有儲存庫。收尾核對原版素材不入 Git、
   目前使用者擁有權、誤建 `.md` 目錄與 Docker 容器清理狀態。

## 停止線

本輪的完成不增加已驗十四段中文顯示；即使來源鏈閉合，也不能
跳過 DRAFT → READY → 正式覆蓋 → 同狀態 CONFORMED。畫面既有
英文及原版行為保持不變，其他旗卡、help 和完整遊玩另列工作。

## 驗收結果

兩次原版 DOS 清冊收據與兩次 RAM 逐字讀寫收據分別位元組相同；
同輸入無觀測控制的 CPU、完整 RAM、原版索引畫面、色盤、ticks、
cycles 及開檔序列均相同。兩個 TXT 候選位移至畫布印字的指令
讀寫鏈已由 `tools/check_goal087_nation_flow.py` 獨立驗證 PASS，
同文替代地址 `0x21ACA` 在印字窗口無讀取。詳細原始位址、
原版 SHA-256、工具版本、收據指紋與仍待驗項目見
[研究紀錄](../../RESEARCH-LOG.md)及[規格021](../spec/021-nation-card-red-text-draft.md)。
此處只關閉來源調查；未製作旗卡中文覆蓋，未更新截圖或十四段計數。
