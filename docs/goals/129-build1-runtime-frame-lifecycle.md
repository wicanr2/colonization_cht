## 已確認決定與界線

使用者已選 `Game Options` A：標題34px，八列依序25／28／28／25／28／28／27／28px，排除B；目標128已記錄、重烘並驗證，不在本輪重做。`@BUILD1` 亦已選A／38px，但尚無正式中文。兩處均維持各自的 DRAFT 規格，不能把字級決定冒稱正式覆蓋。

本輪只處理英格蘭正常玩家路徑中的首張 `@BUILD1` 字幕：確認當次印字事件何時允許中文、每幀何時撤銷，及底圖與色盤的保守回退。不外推其餘字幕、教學 help 或遊戲選項九欄；不改原版 EXE／TXT、RAM、輸入、規則、存檔與點擊熱區。

## 工作與退出條件

1. 核對私有遠端、既有 Issue、合法原版與隔離 dosgolem；先推送本目標及目前脈絡，再執行工程。原版只讀，所有分析、執行、建置、測試和抓圖限 Docker；本機收據僅存已忽略的 `workplace/`。
2. 在既有原版探針增加預設關閉的字幕生命週期觀測，固定 `GAME.TXT` 檔案位移／雜湊、`0D21:00C6` 當次印字與 `0D21:012C` 畫布寫入，記錄畫面與色盤變化、首次可顯示及首次必須撤銷的時點。觀測不能變更 dosgolem 原版狀態；原始位址、步數、版本與證據等級必須保留。
3. 同一正常玩家路徑獨立雙冷啟動並加無觀測控制，核對 CPU、完整 RAM、索引畫布、色盤、虛擬時間、開檔與玩家輸入。獨立正反例涵蓋：未印字、錯版、缺譯、錯畫面／色盤、離頁及回看殘留；缺合法原版須明確跳過。
4. 若來源、相位、逐幀安全矩形、可逆多色底圖、字模與失效條件閉合，先審查限定 `@BUILD1` 的 READY 規格，才接 Ebitengine 真視窗；同輸入英文／中文及原版狀態驗收後才可限定 CONFORMED。任一閘門不成立時只交付可重播 DRAFT 證據，正式中文數不增加。
5. 更新規格、研究紀錄、工作歷程、目前脈絡與唯一工作清單，私有推送並回讀 Issue；核對誤追蹤原版、輸出擁有權及 Docker 清理狀態。
