# 目標 032：`OCEANVS OCCIDENTALIS` 標籤的 canvas 寫入與來源追溯

狀態：completed<br>
日期：2026-09-21<br>
對應 Issue：[Issue #8](https://github.com/wicanr2/colonization_cht/issues/8)<br>
前置證據：[目標 031](031-opening-full-frame-static-text-survey.md)

## 目的

目標 031 已在第一個完整 composite frame 確認 `opening-map-ocean-label` 是可見靜態文字，但沒有資產來源。
本輪只追溯其約略可視矩形 `x∈[53,174)`、`y∈[49,61)` 在 canvas 的內容變更寫入，找出原始 `CS:IP`、步數、
來源暫存器與同時期 DOS 載入事件。只有在來源位址、未覆寫資料與特定檔案讀取閉合時，才可將資產歸屬列為
confirmed；否則保留 unknown／強推論。

## 執行項目

1. 將該矩形換算為 canvas 行內範圍；用其連續外包線性範圍 `[201A5h,2111Eh)` 的 `-watch-file` 監看，並在
   分析時依每列 320-byte stride 篩回真正 `x∈[53,174)` 的位址，避免把矩形外包區的鄰近像素當成標籤。
2. 從固定第 4,156,900 指令 state 重播至第一個完整 copy 的終點，記錄所有受篩選標籤寫入的步數、原始
   `CS:IP`、內容變更與時間群組；同次列出 `OPEN*` 檔案讀取時間，僅作時序交叉索引。
3. 針對實際 writer site 重播並收集 `DS:SI`、`ES:DI`、raw bytes 與附近讀寫；驗證來源是否屬於某一份固定雜湊的
   `.PIK`／`.SS` payload，且在取用前沒有被覆寫。無法閉合時不得以檔名、畫面觀感或載入順序指定來源。
4. 回填收據雜湊、輸入／state、位址空間、推論等級與不足之處至研究紀錄、現況、工作清單、Issue #8、工作歷程與
   Git。無論結果，不建立 DRAFT／READY、覆蓋原型、譯文或中文字型。

## 結果

- 真正標籤矩形的內容變更為 2,345 筆，發生於 #5,432,823–#5,447,038；所有事件的 post-IP 是
  `03BD:00CA`，前一指令 `03BD:00C8` 是 `F3 A5`／`REP MOVSW`。第一個完整標籤列在其前置狀態為
  `DS:SI=388B:5DF5`、`ES:DI=1E23:1F40`、`CX=00A0`；來源線性範圍的該列標籤部分是
  `[3E6A5h,3E71Eh)`，目的 canvas 的對應部分是 `[201A5h,2021Eh)`。
- 在正常 BIOS Enter 路徑，該來源切片僅有 120 筆**內容變更**，全在 #3,225,029–#3,225,927，分別由
  `0AC2:04F5`（前一指令 `MOVSB`）15 筆與 `0AC2:0551`（前一指令 `STOSB`）105 筆寫入。從此後至第一筆
  標籤 canvas 寫入前，監看未見該切片的內容變更；此觀測不排除值相同寫入。
- `OPENING.PIK` 的主要 payload 已在 #3,004,029／#3,004,090 讀入 `5755` 緩衝區。15 筆 `MOVSB` 可在同一步數
  精確配對為該原始緩衝區讀取至標籤暫存切片：第一筆 #3,225,029 是 `5C457h → 3E6A5h`，最後一筆
  #3,225,927 是 `5C497h → 3E71Dh`。其餘 105 筆由同一個以 `DS=5755` 執行的解碼迴圈之 `STOSB` 分支產生。
- 因此 `OPENING.PIK` 對標籤暫存切片的 15 個直接像素來源是 **confirmed**；整個標籤由
  `OPENING.PIK` 解碼而來是**強推論**，而非完整逐像素資料依賴已證實。這與目標 027 的勘誤不矛盾：當時遭
  `OPENBORD.PIK` 覆寫的是較晚的 `5755`→頂端邊框路徑；本輪的標籤資料早已寫入另一個暫存切片並存續至畫布。
- `OPENING.PIK` 是否可作為整則標籤的唯一資產歸屬、copy 後穩定畫面存續與中文安全矩形，仍為 unknown；不建立
  DRAFT／READY、覆蓋原型、譯文或字型決策。
