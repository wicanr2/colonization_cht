## 玩家問題與範圍

右上相鄰旗卡的 `FRANCE:`／`Cooperation` 已有固定原始來源與畫布
印字證據，畫面仍是英文；目前缺少印字前底圖、安全矩形及符合各欄
原文字級的中文視覺收據。本輪只建立「法國：／合作」的本機可丟棄
預覽，不修改正式輸出、不更新成果截圖，也不將第一張旗卡未決的
A／B 字級直接套到右側。

## 執行與退出條件

1. 先推送本目標到核對為 PRIVATE 的儲存庫。固定合法 DOS 輸入、
   隔離 dosgolem、真視窗16筆輸入與目標090來源鏈；所有程式執行、
   分析、建置、測試及抓圖都在限資源 Docker，原版與字型唯讀掛載。
2. 在原版兩欄精確印字事件前後擷取320×200索引畫布，分開量測
   原文字墨跡、色號、底圖紋理及可逆補片；不得以鄰近純色取代底圖，
   也不得把左側舊欄清除差分當成右側新字。
3. 各欄獨立提出中文字級、文字框、內距與安全矩形，檢查最長譯文、
   字形覆蓋、原版四倍墨跡及旗面邊界。若證據不足，維持原文。
4. 以既有 Ebitengine 預覽機制產生英文控制與中文候選，獨立驗證
   安全區外零差異、透明中文字模下逐像素恢復原背景，以及原版
   CPU／RAM／索引畫面／色盤／時間的同輸入不變。原始像素、圖像、
   字型與 RAM 只留 `workplace/`，不得加入 Git。
5. 將量測與不足回填規格022、研究紀錄、`CONTEXT.md`、唯一工作
   清單及 `WORKLOG.md`；推送私有儲存庫、更新 Issue。收尾核對
   原版素材未入 Git、檔案擁有權、誤建目錄與 Docker 清理狀態。

## 停止線

原型不等於 READY 或正式玩家畫面驗收。右側欄位仍須執行期游標、
按鍵、切卡、離頁及缺譯／缺字／錯版本逐欄回退，經證據審查、
正式前端實作及真視窗中英文同狀態驗證後，才可增加十四段正式
中文顯示數。第一張旗卡的 A／B 視覺選擇保持獨立待確認。

## 本輪結果

雙次 dosgolem 原版精確重播位元組相同，無監看控制的 CPU、
完整 RAM、索引、色盤、時間、開檔與畫布同狀態；右側原文上／下行
可見差分100／136點。印字前安全區各有45／80種色號，已取得
各自可逆補片與非重疊安全矩形，詳細步數及 SHA-256 見
[規格022](../spec/022-neighbor-nation-card-red-text-draft.md)。
原版右側字用藍色索引9，不是第一張旗卡的紅色索引12；這項更正
已寫入規格與研究紀錄。

本機 Ebitengine 原文控制與兩個中文候選均通過逐像素驗證：
較貼近原文墨跡的21／25px、較易讀的25／29px，各只改右上旗卡
兩個安全區，透明字模下恢復當次多色底圖，藍色前景與黑影均在
原版色盤。原文、字型、預覽 PNG 與完整收據只留
`workplace/reports/goal091-neighbor-preview/`，沒有進 Git。

兩個候選都只是可丟棄視覺樣本，右側字級尚未定案；第一張旗卡
另有自己的 A／B 待確認。正式前端、十四段顯示數及私有成果截圖
均未變。下一輪仍須執行期回退與 READY 閘門，不能用預覽通過
代替正常玩家路徑驗收。
