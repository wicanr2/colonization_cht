# 目標176：前端音訊輸出（Issue #49）

狀態：進行中；開始：2026-09-30。對應 [Issue #49](https://github.com/wicanr2/colonization_cht/issues/49)，規格見[規格040](../spec/040-frontend-audio.md)。

## 已知

- dosgolem 隔離副本已有 OPL3 合成（規格037）與數位音效（規格039），`DrainAudio()` 回交錯 int16 立體聲，取樣率 49,715 Hz；兩者都不回寫機器狀態（數位音效開啟會讓驅動走數位音效可用的路徑，這是機器行為，與播放無關）。
- 視窗前端每次 `Update` 推進 200,000 道指令；dosgolem 時鐘約每秒 11.58M 道指令，所以全速時模擬時間約為實際時間的 1.036 倍。

## 範圍

1. 規格040：`--audio` 開啟 OPL 合成與前端播放、`--audio-wav` 錄下 dosgolem 原始取樣；播放以 48 kHz 串流，積壓與不足的處理不回饋到模擬節奏。
2. 真 GUI：開場音樂、海上音樂、建城木刻畫面的數位音效；錄出的 WAV 與同輸入無頭重播的 WAV 逐位元組相同。
3. 開關音訊：同輸入重播的原版 RAM、畫面、檢查點與步數完全相同。
