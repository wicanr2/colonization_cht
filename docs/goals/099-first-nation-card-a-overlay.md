# 目標099：第一張國家旗卡 A 版正式中文覆蓋

狀態：completed（僅第一張旗卡 A 版兩欄）；日期：2026-09-24。承接使用者從四格對照選定的
**A 版**：「英格蘭：」21px、「移民」25px，排除 B 的25／29px；
源自[目標088](088-first-nation-card-reversible-preview.md)、
[目標089](089-first-nation-card-runtime-guard-evidence.md)與
[規格021](../spec/021-nation-card-red-text-draft.md)，對應
[Issue #12](https://github.com/wicanr2/colonization_cht/issues/12)、
[Issue #26](https://github.com/wicanr2/colonization_cht/issues/26)。

## 玩家問題與界線

國家選擇頁第一張旗卡仍顯示動態英文 `ENGLAND:`／`Immigration`。
已有原版來源、精確印前多色底圖、兩欄 A 版可逆 Ebitengine 原型，
以及游標、左鍵與相鄰旗卡重繪的正常玩家負例；但原型不是正式
輸出。這輪目標是依已選 A 版把**第一張**卡片兩欄接入正式中文
顯示、逐欄回退並完成中英文同狀態驗證；相鄰右卡視覺字級尚未
由使用者定案，不在本輪擅自複製 A。原版 EXE、TXT、規則、
滑鼠命中、姓名與存檔均不修改。

## 工作與退出條件

1. 先把本目標推送至已核對 PRIVATE 的 `origin/main`；鎖定合法 DOS
   原版雜湊、隔離 `workplace/dosgolem` 提交、真 TSV、A 版原型與
   既有 Ebitengine 正式十五欄基線。工作只在 UID/GID 持有、限資源
   Docker 執行，原版與字型唯讀；含原版畫素的產物只留 `workplace/`。
2. 確認原型所用 Cubic 11 固定 SHA-256 的字型或已驗同源字模仍可
   重生；缺原件不可用相似字型偷換，也不可把無來源的緩存字模
   當成可公開資產。整理兩欄 A 版的原文／譯文、紅字／黑影、
   半開安全矩形、內距、最長字串與錯版條件。
3. 把目標089的游標只遮上欄／只遮下欄、下欄左鍵按下／放開、
   相鄰右上卡重繪與選國離頁負例納入正式逐欄守門規格；補足
   仍缺的當次來源事件與反向條件。證據足夠才把規格021升
   限定 READY；否則保持 DRAFT 並先做可丟棄驗證。
4. 只依 READY 規格從真 TSV 及固定 A 字模接入正式 Ebitengine
   輸出；缺鍵、重複鍵、缺字模、尺寸不符、背景／印字／頁相位
   不符與游標遮擋均逐欄回退原文。保持現有十五欄內容及
   相鄰右卡畫素不變，原版資料與 CPU／RAM／索引／色盤／時間
   完全不受中文顯示影響。
5. 真 Ebitengine 視窗由冷啟動、正常滑鼠路徑到第一張卡，與
   同輸入英文控制及舊版比對。核對兩欄安全區外零差異、A 版
   字級／位置、上／下欄獨立游標回退、換卡、離頁、缺譯／
   缺字模／錯版，以及第二張卡片和既有標題不回歸。
   全部通過才標記規格021限定 CONFORMED，正式顯示由十五增為
   十七段；否則不改計數、不更新私有截圖。
6. 回填 `CONTEXT.md`、`RESEARCH-LOG.md`、`WORKLOG.md`、唯一工作
   清單與遠端 Issue，推送私有儲存庫。核對原版素材／字型未入
   Git、隔離 dosgolem 上游推送禁用、輸出擁有權、誤建目錄與
   Docker 容器清理。

## 停止線

使用者只決定第一張旗卡的 A 版字高，不表示相鄰右卡、其他國家、
國家介紹長文或整頁已完成。規格 DRAFT 不接正式前端；可丟棄
原型不能充當真視窗玩家路徑、缺譯回退或同狀態收據。固定字型
與已驗同源字模均無法取得／驗證時，仍可完成不依賴它們的原版
負例與規格證據，但不得偽造正式字模或宣稱兩欄 CONFORMED。

## 驗收結果

隔離 dosgolem 冷啟動雙重播及無觀測控制確認第一張旗卡完成區
可直接離頁；原版 CPU、完整 RAM、畫布、色盤、時間與開檔序列一致。
規格021已先限定 READY，才接入 `tools/live_menu.go` 的
`--nation-card-a`，最後依真 Ebitengine 視窗、同輸入英文控制與
舊十五欄版核對為限定 CONFORMED。旗卡上、下兩欄分別使用
21／25px，畫面差分1,915／2,738個四倍輸出像素，安全區外零差異；
舊十五欄逐幀狀態不變，原版 CPU／RAM／索引／色盤／時間／開檔
完全相同。真視窗截圖已核對後加入私有 `docs/screenshots/`。

同輸入重播驗缺上欄譯文、下欄重複鍵、上欄缺字模、下欄錯字級
的逐欄回退；上／下游標、移開、下欄按住、切到相鄰右卡與
直接離頁六例也依原版畫面時序回退。換卡及離頁後整張畫面
與未啟用新覆蓋的同輸入版逐像素相同；錯版原版於啟動前拒絕。
本機驗證入口為 `tools/verify_goal099_card_a.py` 與
`tools/verify_goal099_runtime.py`。固定 Cubic 11 原始 TTF
仍未恢復；本機字模只從先前已驗同源原型提取，未加入 Git，
不可宣稱可獨立公開重烘或發行。相鄰右卡及其他國家仍未中文化。
