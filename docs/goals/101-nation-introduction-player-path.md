# 目標101：四國介紹的正常玩家路徑與翻頁收據

狀態：進行中；日期：2026-09-24。承接[目標100](100-all-nation-introduction-bilingual-corpus.md)
的四國八節雙語草稿與[規格025](../spec/025-first-nation-introduction-draft.md)，
對應 [Issue #30](https://github.com/wicanr2/colonization_cht/issues/30)。

## 玩家問題與範圍

目前只以 dosgolem 從正常玩家流程證實法國 A／B 介紹的原版印字與畫布。
英格蘭、西班牙、荷蘭雖有固定來源譯稿，仍不知實際如何從選國頁進入、
各頁何時顯示、標題／正文實際墨跡以及 B 頁之後如何離開。這些不是
能由 `GAME.TXT` 的節名推定的事。本輪以真實滑鼠與鍵盤走四國流程，
建立可重播頁相位及原版畫面收據，供後續逐頁量測中文安全矩形。

本輪**不**替換原版文字、不決定長文中文字級、不修改原版資料、規則、
姓名、存檔或玩家流程。第一次找路可用可丟棄探針；正式證據必須
由 dosgolem 正常冷啟動重生，不能由檔案節存在或 DOSBox 圖片冒充。

## 固定輸入與證據閘門

- 合法 DOS `GAME.TXT` SHA-256 為
  `67a6b5e22d1addc1ae13658d0d7824622f6d21c6c2bfdefc91f9749450cc2e3a`；
  其他 EXE／TXT／PIK 以目標098的固定指紋檢查。原版只讀掛載。
- 本專案只用 `workplace/dosgolem` 獨立副本，`upstream` 推送位址保持
  `DISABLED`。研究輸出只在 gitignore 的 `workplace/`；原版畫素、
  RAM 與完整印字串不得加入 Git。
- 各項結論分開標示：`GAME.TXT` 檔案位移、DOS 讀入目的線性 RAM、
  印字實模式 `CS:IP`、320×200 原版索引畫布及 1280×800 顯示畫布；
  「預讀」不可冒稱為「已顯示」。
- 規格025維持 DRAFT，直至字型、各欄安全矩形、最長譯文換行、
  頁相位及失敗回退均能經獨立審查，才可另行升 READY。

## 工作與退出條件

1. 先把本 goal 推送至已核對 PRIVATE 的 `origin/main`；回讀 Issue #30
   OPEN、Git 作者身分與乾淨工作樹。複用既有正常玩家輸入，不能
   以改 RAM／跳入口選國。
2. 以可重播的滑鼠動作從選國頁分別選英、法、西、荷；每條路徑
   記錄選國前後的原版索引畫面、輸入步數、姓名頁及其相位。
   找不到某國時記錄已試操作與可見反證，勿憑卡片順序猜中。
3. 每國由姓名頁實際 Enter 進 A 頁，再由正常 Enter 進 B 頁；
   逐頁核對固定來源節的 DOS 讀取、印字讀取、畫布寫入與穩定
   畫面雜湊。至少兩次獨立冷啟動與無觀測控制，核對 CPU、完整
   RAM、索引、色盤、虛擬時間及開檔一致。
4. 以至少一國的 B 頁測第三次 Enter 與 ESC，判定正常離頁／
   回退；若出現未支援服務、無法重播或不同意的狀態，先記錄
   最小重現與證據等級，不將未知寫進正式顯示。
5. 根據已驗結果更新規格025的原版頁相位及墨跡資料，保留
   中文安全矩形、字級與回退的未知；回填 `CONTEXT.md`、
   `RESEARCH-LOG.md`、`WORKLOG.md`、唯一 `docs/worklist.json`
   並重生 `WORKLIST.md`。更新、回讀 Issue #30 後推送成果。
6. 收尾檢查：Git 沒有原版素材／字模／本機收據、Docker
   容器已清理、沒有 root-owned 或誤建 `.md` 目錄、輸出
   UID/GID 正確，隔離 dosgolem 未推向共享上游。

## 完成語意

本輪只在實際重播到的國家與頁面宣稱原版正常路徑已證實；
不因取得四國八節來源或畫面就把長文稱為中文顯示完成。
正式顯示計數仍維持十七段，直到長文覆蓋另經 READY →
實作 → 同狀態驗證 → CONFORMED。
