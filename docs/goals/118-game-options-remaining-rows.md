狀態：in_progress；日期：2026-09-24。承接[目標117](117-game-options-same-focus-checkmarks.md)與[規格027](../spec/027-game-options-window-draft.md)，對應既有 [Issue #7](https://github.com/wicanr2/colonization_cht/issues/7)和 [Issue #26](https://github.com/wicanr2/colonization_cht/issues/26)。不另開同義 Issue。

## 玩家問題與範圍

原版 `Game Options` 八列中，第4／7／8列已在點回第1列的同焦點對照下，證實各自圖示中心四點會保留變化；第2／3／5／6列尚未有相同收據。正式繁中圖層若只憑已見列推測其餘列，可能抹掉原版核取圖示或蓋過焦點畫素。本輪要沿同一正常玩家路徑補齊這四列，整理八列穩定畫面矩陣與仍未知的瞬間相位；不修改原版、遊戲規則、譯文或正式 Ebitengine 輸出。

## 工作與驗收

1. 核對乾淨工作樹、PRIVATE 遠端／Issue、固定 DOS 原版與隔離 `workplace/dosgolem`；**先推送本目標 Markdown 和 `CONTEXT.md` 入口**，再建立新玩家事件或跑原版。沿用 `colonization-research:20260920-r2`，只在無網路、限資源、非 root、一次性 Docker 中執行，原版唯讀，原始像素／完整收據僅在已忽略 `workplace/`。
2. 每列獨立由已驗正常英格蘭玩家路徑進入設定視窗：1,302M／1,303M點第2列 `(140,77)`、第3列 `(140,89)`、第5列 `(140,113)` 或第6列 `(140,125)`；1,352M／1,353M一律點回第1列 `(140,65)`。四列各做雙冷啟動與無監看控制；只點第1列的[目標117基線](117-game-options-same-focus-checkmarks.md)若固定版本和輸入完全一致可重用，否則重新重播。核對原版 `route`、CPU／完整 RAM、索引／底層畫布、色盤、時間、開檔與輸入事件，不能只憑事件檔宣稱點擊生效。
3. 對1,300M共同起點、1,325M／1,350M暫態及1,375M／1,400M同焦點終點，量每列原版畫素差分與精確色號；區分焦點、文字與核取圖示，不把某個色號直接命名為選項開或關。建立獨立檢查器和原始畫面、事件、錯版、控制分歧、差分越界、缺原版 `SKIP 77` 負例；若某列不是四點圖示，照實保存，不套用先前列的模式。
4. 把八列中已有的同焦點穩定相位及剩餘未知回填規格027、`RESEARCH-LOG.md`、`CONTEXT.md`、`WORKLOG.md` 與唯一 `docs/worklist.json`，重生 `WORKLIST.md`；推送 PRIVATE 儲存庫，更新／回讀既有 Issue。收尾核對輸出擁有權、原版／字型／像素未入 Git、隔離 dosgolem 禁推與 Docker 容器清理。
