## 玩家問題與範圍

相鄰右上旗卡的「法國：／合作」已有原始來源、可逆底圖及可丟棄
中文畫面，但執行期游標、按鍵及換卡時能否安全顯示仍未知。
正常玩家路徑也只證實到選國頁，尚不知道點選右卡後哪些可見
操作會進入下一個畫面。本輪先量原版的輸入、畫布與狀態轉移，
同時尋找下一個可重播玩家畫面；不替使用者選 A／B 字級、
不把原型接入正式前端。

## 執行與退出條件

1. 先推送本目標到確認為 PRIVATE 的儲存庫。以固定合法 DOS
   原版雜湊、隔離 dosgolem、16筆真視窗輸入及目標090／091
   的右卡來源與畫布收據為起點。全部探針、建置、測試及畫面
   工作只在限資源 Docker；原版唯讀，輸出留 `workplace/`。
2. 正常玩家輸入進入右卡後，逐欄測試游標停留上方文字、下方
   文字與移開；再測試右卡的左鍵按下／放開及可辨識的換卡
   反例。記錄每個檢查點的底層畫布、索引畫面、色盤、滑鼠
   狀態、CPU／RAM／虛擬時間、開檔序列，區分游標遮擋、
   文字重繪及場景改變。
3. 在原版可見提示與安全選區內，探索選國後的下一個正常
   玩家動作；不得用 direct-entry、記憶體注入或猜測的快捷鍵
   假裝到達。如果原版在固定時間窗沒有離頁，記錄輸入、
   原版狀態、可見提示及尚未驗證的選項，不宣稱玩家路徑已通。
4. 每個肯定或否定結論至少雙次獨立冷啟動及無逐幀觀測
   控制，建立獨立驗證器檢查同狀態與逐欄安全區差分。
   目標089左卡負例不得直接外推到右卡；若流程有新文字，
   只立可追溯的 DRAFT 候選，不直接接正式覆蓋。
5. 更新規格022、研究紀錄、`CONTEXT.md`、唯一工作清單與
   `WORKLOG.md`；推送私有 repo 並回填 Issue。收尾檢查
   原版素材未入 Git、輸出 UID/GID、誤建目錄及 Docker 清理。

## 停止線

本輪只取得原版執行期證據與可達性；不升格正式旗卡覆蓋、
不更新成果截圖，也不增加十四段正式顯示數。若右卡正式
回退契約或選國行為仍有未知，規格022保持 DRAFT；後續
READY 審查與真視窗中英文同狀態驗收另立明確目標。
