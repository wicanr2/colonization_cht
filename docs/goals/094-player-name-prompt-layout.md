# 目標094：姓名提示的可逆底圖與中文排版

狀態：完成（限可逆排版證據，正式覆蓋仍 DRAFT）；日期：2026-09-24。承接[目標093](093-player-name-source-and-input.md)、
[規格023](../spec/023-player-name-screen-draft.md)，對應
[Issue #29](https://github.com/wicanr2/colonization_cht/issues/29)。

## 玩家問題與範圍

正常玩家已能抵達「Please Enter Your Name.」提示，來源與原版動態印字
已證實，但尚不能安全蓋上「請輸入您的姓名。」：提示下方是多色圖像，
又鄰接可編輯的玩家姓名。這一輪只處理固定提示的顯示層；預設姓名仍
交由原版編輯，不改其記憶體、規則或存檔。首次國家介紹長文屬
[Issue #30](https://github.com/wicanr2/colonization_cht/issues/30)，不在此輪擅自覆蓋。

## 執行與退出條件

1. 先推送本目標至已核對為 PRIVATE 的儲存庫，再用隔離
   `workplace/dosgolem`、固定原版雜湊與既有正常玩家輸入，於有界
   Docker 重播。原版唯讀；索引、色盤、RAM 與 PNG 只存已忽略的
   `workplace/`。雙次獨立冷啟動加無畫布觀測控制。
2. 以原版提示輸出事件的精確前後相位量測墨跡、基線、周圍顏色、
   面板界線及可重建的印前底圖；給出提示專屬四倍安全矩形、內距、
   最長譯文及中文字級候選。不得沿用其他畫面的固定字級或以
   單色擦拭取代多色背景。
3. 驗證同一畫面下姓名欄字元、退格、游標與 Enter 轉場的負例：
   固定提示不得污染可編輯姓名，也不得在離頁後殘留。可丟棄
   Ebitengine 原型須與同輸入英文控制比較，並只在提示安全區有差異。
4. 將來源、幾何、回退與證據等級回填規格023、研究紀錄、現況及
   工作清單。若證據足以升 READY，才接正式前端並重跑中英文
   同狀態、缺鍵／缺字／錯版及正常玩家輸入驗收；否則停於 DRAFT，
   保留原文與既有十四段正式中文顯示。
5. 更新 `WORKLOG.md` 及 Issue #29，推送結果。核對原版素材沒有被
   Git 追蹤、輸出 UID/GID、誤建目錄與本專案 Docker 容器清理。

## 停止線

不得因「提示文字固定」就將玩家姓名當成可翻譯常數；不得把本機
原型算作正式中文顯示。若印前底圖或字級證據不足，明列缺口，
不以猜測色塊或裁切掩蓋。

## 本輪結果

雙次獨立冷啟動與無觀測控制取得48,696,982步提示印前畫布及
48,721,827步印後畫布；`0D21:00C6` 讀回完整可見提示，
`0D21:012C` 僅改415點，原版墨跡右下不含框為
`(104,88)–(215,97)`。安全矩形定在`(100,85)–(219,98)`；
其底圖有10種色號，印後至55M步保持一致。y=98的輸入框上緣
會在提示後另行重繪，故刻意排除。精確相位、雜湊及位址空間見
[規格023](../spec/023-player-name-screen-draft.md)與研究紀錄。

主譯稿同一來源鍵的 `^^請輸入您的姓名。` 只繪製可見段；
`^^` 仍留在控制碼資料中。Cubic 11 38px候選墨跡
328×35px，對照原版放大後約36px墨跡高，中心對齊在
四倍畫布 `(474,352)`。Ebitengine 對無輸入、輸入 `x`、
退格三種本機原型各只在提示安全區改9,520個畫素；英文
控制圖逐像素等於 dosgolem，姓名欄完全不變。獨立 PASS
收據 SHA-256
`b682921086f1c92f016ae4095a3d6684af095b40020ce43999c01507e9b31ed1`。

這仍是可丟棄原型：現行正式視窗只轉送 Enter，未處理一般
字元／退格；提示事件的執行期守門、缺鍵／缺字與離頁回退也
未接正式前端。規格023維持 DRAFT、Issue #29保持開放，
正式中文顯示仍十四段。下一步須先補有證據的玩家鍵盤路徑
與逐欄守門，再做 READY 審查及中英文同狀態驗收。
