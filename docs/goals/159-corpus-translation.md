# 目標159：未建檔遊戲文字的繁中語料（Issue #27 第五輪）

狀態：完成（草稿）；開始與完成：2026-09-26。對應 [Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)，分母見[目標158](158-text-denominator.md)。

## 範圍

- 目標158 的 1,797 行未建檔遊戲畫面文字，依段落合併成訊息單位，譯成繁體中文草稿。
- 新清冊 `text/corpus.zh-Hant.tsv`：與正式欄位綁定的 `draft.zh-Hant.tsv` 分開，新增語料不使既有字模失效。
- 每列有來源檔 SHA-256、位移、長度、片段 SHA-256；控制碼（`%STRINGn`、`{}`、`^`、`~` 熱鍵、`$` 變數）順序與數量不變；用字在 Cubic 11 內；術語依 `text/terms.zh-Hant.tsv`。
- 流程依批次在地化：切批 → 共用指令檔 → 試作一批審閱 → 平行 → 合併逐列驗證 → 術語檢查 → 分母重算。

## 退出條件

- 分母重算後遊戲畫面未建檔行數為 0，或剩餘者逐項寫明不譯理由。
- 合併驗證與術語檢查通過。
- 這些是草稿；畫面顯示另依各欄位規格處理。

## 結果

- `tools/prep_corpus_batches.py` 把 1,797 行切成 867 則（散文依段落合併、清單每行一則），16 批。試作一批審閱後，其餘由子代理平行翻譯；`tools/merge_corpus.py` 逐筆驗證後寫入 `text/corpus.zh-Hant.tsv`（867 列：草稿 864、刻意留空 3）。
- 驗證項：來源片段 SHA-256、控制碼數量（有編號的 `%STRINGn`／`%NUMBERn` 可依中文語序移動，`^` 與 `@` 控制行順序不變，大括號成對）、清單類行數、Cubic 11 字形、常見簡體字、英文引號。
- 術語：對語料跑 `tools/check_glossary.py` 得 53 列衝突，修正 22 列（食物、殖民領地、反叛、伏襲、交易商品等），其餘在 notes 寫明不換理由（同形異義、專有名詞、曲名、資料行註解）。同英文不同譯的全域掃描只剩 Land（「陸上」路線類型與「陸地」地形兩個語境）。
- 分母重算：遊戲畫面 3,561 行全部已抽取，已翻譯 3,558、刻意留空 3（英文冠詞）。摘要 SHA-256 `b74db14ba1f22d4711169fe168bc667631c0c10ee2c36bdbec77471e49eb01ff`；清冊 SHA-256 `1483f5ce585c43337dbab8118928cff783af936682493e1fc5e5f2b6554c2947`。

## 已知限制與後續

- 這些是草稿，沒有畫面證據；正常路徑中文顯示仍依各欄位規格逐項實作與驗證。
- LABELS.TXT 有許多在執行期拼接的片段（例如 Land／of the、Not enough／to fill cargo hold!）；中文語序可能與英文拼接順序不同，實作顯示時要以整句模板處理，不能逐片段替換。
- 占位符改依編號代入：顯示層要支援同一模板中 `%STRINGn` 位置與英文不同。
- 曲名、傭兵階級、次要部落名、`@SCORE` 文字遊戲清單等是子代理自譯，未經說明書對照，notes 已標示。
