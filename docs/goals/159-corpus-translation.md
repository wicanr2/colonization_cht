# 目標159：未建檔遊戲文字的繁中語料（Issue #27 第五輪）

狀態：進行中；開始：2026-09-26。對應 [Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)，分母見[目標158](158-text-denominator.md)。

## 範圍

- 目標158 的 1,797 行未建檔遊戲畫面文字，依段落合併成訊息單位，譯成繁體中文草稿。
- 新清冊 `text/corpus.zh-Hant.tsv`：與正式欄位綁定的 `draft.zh-Hant.tsv` 分開，新增語料不使既有字模失效。
- 每列有來源檔 SHA-256、位移、長度、片段 SHA-256；控制碼（`%STRINGn`、`{}`、`^`、`~` 熱鍵、`$` 變數）順序與數量不變；用字在 Cubic 11 內；術語依 `text/terms.zh-Hant.tsv`。
- 流程依批次在地化：切批 → 共用指令檔 → 試作一批審閱 → 平行 → 合併逐列驗證 → 術語檢查 → 分母重算。

## 退出條件

- 分母重算後遊戲畫面未建檔行數為 0，或剩餘者逐項寫明不譯理由。
- 合併驗證與術語檢查通過。
- 這些是草稿；畫面顯示另依各欄位規格處理。
