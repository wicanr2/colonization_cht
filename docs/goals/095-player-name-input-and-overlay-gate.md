# 目標095：姓名畫面的真視窗鍵盤與提示正式覆蓋閘門

狀態：進行中；日期：2026-09-24。承接[目標094](094-player-name-prompt-layout.md)、
[規格023](../spec/023-player-name-screen-draft.md)，對應
[Issue #29](https://github.com/wicanr2/colonization_cht/issues/29)及
[Issue #26](https://github.com/wicanr2/colonization_cht/issues/26)。

## 玩家問題與範圍

原版姓名欄可以輸入、退格並按 Enter 繼續，但現行 Ebitengine 視窗
只轉送 Enter。固定提示已有可逆中文排版原型，仍缺正式執行期
守門與回退。本輪要把正常玩家鍵盤路徑接回 dosgolem，再審查
是否足以讓「請輸入您的姓名。」從原型進入正式顯示；不翻譯
可編輯姓名，也不改原版資料、規則或存檔。

## 執行與退出條件

1. 先把本目標推送已核對為 PRIVATE 的儲存庫。讀取固定原版、
   隔離 `workplace/dosgolem` 與既有雙次原版收據；所有分析、
   建置、測試、抓圖只在有界 Docker，原版唯讀，輸出只放
   已忽略的 `workplace/`。
2. 確認視窗按鍵到 DOS 掃描碼／ASCII 的來源與邊界。先以已證
   `x`、退格、Enter 做可重播正常玩家驗收；如要擴大到其他
   字元，須有平台契約與實際原版消費證據。寫成限定 READY
   規格後才改正式前端；輸入收據須保存原始按鍵，不把譯文
   寫回遊戲記憶體。
3. 審查規格023的固定提示來源、印前10色底圖、安全矩形及
   38px字模是否足以描述執行期狀態、逐欄回退與離頁失效。
   若足夠，先升限定 READY，再接正式疊加；若缺守門證據，
   窄追原版重繪／游標／檔案開啟相位，不從預覽器直接搬程式。
4. 以真 Ebitengine 視窗、同一份原版及可重播玩家輸入，
   比較中文、英文控制與缺鍵／重複鍵／缺字／錯版反例。
   至少驗輸入字元、退格、Enter 離頁；CPU、完整 RAM、
   原版索引、色盤、時間、開檔須同狀態，中文差異僅限提示
   安全區，姓名欄不得受翻譯影響。只有全過才標限定
   CONFORMED 並更新正式段數。
5. 將結果、推論等級、限制與下一步回填規格、`CONTEXT.md`、
   研究紀錄、唯一工作清單及 `WORKLOG.md`；推送私有 repo 並
   更新 Issue #29／#26。核對素材未被追蹤、輸出權限、誤建
   目錄及本專案 Docker 容器清理。

## 停止線

不以直接 `PushKey` 探針代替真視窗按鍵；不把可丟棄原型
算成正式顯示。若鍵盤映射、游標或提示生命週期不能通過
READY／同狀態驗收，保持規格023 DRAFT、原文與十四段
正式數量，並明列下一個最小可重現缺口。
