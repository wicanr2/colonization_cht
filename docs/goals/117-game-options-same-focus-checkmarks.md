## 工作與驗收

1. 核對 PRIVATE 遠端、Git 作者、固定原版、既有收據及隔離 `workplace/dosgolem`；**先推送本目標 Markdown 與 `CONTEXT.md` 入口**，再新增玩家事件或執行原版。研究只在限資源、無網路、非 root、一次性 Docker；合法原版唯讀，原版畫素／完整記憶體只留已忽略 `workplace/`。
2. 沿固定正常玩家路徑開窗，在1,302M／1,303M點第4列與第7列，1,352M／1,353M點回第1列；另跑只點第1列基線。各支以同終點、同游標、同焦點比較原版320×200底層畫布與合成索引、色盤、CPU／RAM、虛擬時間及開檔。原版確實消費輸入、進入相同焦點須由畫面證實，不能只看事件檔。
