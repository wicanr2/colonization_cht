# 目標 033：海洋標籤的 copy 後存續與顯示區邊界

狀態：completed<br>
日期：2026-09-21<br>
對應 Issue：[Issue #8](https://github.com/wicanr2/colonization_cht/issues/8)<br>
前置證據：[目標 031](031-opening-full-frame-static-text-survey.md)、[目標 032](032-ocean-label-canvas-writer-provenance.md)

## 目的

目標 032 已確認 `OCEANVS OCCIDENTALIS` 的部分 `OPENING.PIK`→暫存→畫布資料流，但靜態中文覆蓋仍須知道：
第一個完整 composite copy 後，標籤的畫布來源與 A000 顯示像素是否在正常 BIOS Enter 路徑中維持可辨識的同一狀態。
本輪只建立該時間邊界與顯示區的可重播收據，不把文字外框升格為中文安全矩形。

## 執行項目

1. 從目標 031 的 #5,465,772 首個完整 composite copy 完成 state，重播至既有開場候選清冊終點 #5,500,000；分別監看
   標籤真正 12 列的畫布範圍與 A000 對應顯示範圍。外包線性範圍僅用於收集，分析時必須依 320-byte stride 篩回
   `x∈[53,174)`、`y∈[49,61)`，不得混入列間的鄰近圖像。
2. 以固定起點與終點重生 indexed frame／palette（僅留在 `workplace/reports/`），比較全畫面與標籤精確矩形的
   色號；將「無內容變更」「有變更後回復」與「最終不同」三種結果分開記錄。watch 只能排除內容變更，不能單獨
   排除值相同寫入。
3. 若 A000 標籤像素在終點仍與首個完整 frame 相同，記錄這僅證明本正常路徑窗口的顯示存續；若不同，保留每個
   writer site、步數與最終差異，不猜測動畫或資產語意。畫布暫存區的結果必須與 A000 結果分開，不以其中一者
   代替另一者。
4. 回填收據雜湊、原始定位、位址空間、推論等級與未解項至研究紀錄、現況、工作清單、Issue #8、工作歷程與 Git。
   無論結果，不建立 DRAFT／READY、覆蓋原型、譯文、字型或原版衍生版控內容。

## 結果

- 以目標 031 的正常 BIOS Enter 路徑，在第 #5,465,772 指令的第一個完整 composite copy 後建立可重載 state；
  兩條獨立重播均至 #5,500,000，程式持續於 mode 13h，未見未實作服務或新檔案開啟。
- 畫布（canvas）的 12 列精確標籤範圍 `201A5h–20FDDh` 與 A000 顯示範圍 `A3D75h–A4BADh` 各自的內容變更
  watch TSV 均為零位元組。這是該範圍在這個窗口沒有內容變更的 confirmed 證據；不能排除值相同寫入。
- 起點與終點的整張 320×200 色號陣列、256×RGB 調色盤以 `cmp` 逐位元組相同，SHA-256 分別為
  `304ffd302045969ddad4a6c5e3c139a1af5f9f1bdbc1a060600b981ef26faeaf` 與
  `000ee1dfbfba6afc159d4e39dca09e5202e68bebc931cd4d50bfb3f998e1f1e3`；精確標籤裁切的兩份放大 PNG 亦同為
  `816fb640eef2583dfc3471cf92db4ed15fb80c0ee795f67917d3de6c04bf4875`。
- 因此可確認 `OCEANVS OCCIDENTALIS` 在 #5,465,772–#5,500,000 的這條正常路徑窗口持續顯示於同一畫布／
  A000 像素狀態；這不宣稱永續穩定、完整資產歸屬、中文安全矩形或覆蓋資格。未建立 DRAFT／READY、覆蓋原型、
  譯文或字型。

## 停止線

- 不把目標 031 的完整 frame、匹配的全畫面雜湊或「沒有新內容變更」單獨誤稱為永久畫面穩定性；結論只限
  #5,465,772–#5,500,000 的已確認正常路徑窗口。
- 不把可見文字矩形、畫布來源矩形或 A000 矩形當作中文安全矩形；安全內距、清除策略、中文字型及最長譯文仍是
  獨立的後續閘門。
- 不 OCR、解包、修改原版、記憶體注入、修改 dosgolem，或把 frame、palette、crop、原始 bytes 附到 GitHub。
