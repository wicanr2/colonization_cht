# 目標167：其餘教學提示（Issue #43）

狀態：進行中；開始：2026-09-28。對應 [Issue #43](https://github.com/wicanr2/colonization_cht/issues/43)。

## 已知

- 教學提示只在第一張難度卡（Discoverer）且開啟教學時出現；首則 `@TUTORIAL1` 已由規格026 的專屬欄位處理（目標142）。
- help 雙語清冊 `text/help-bilingual.tsv` 有 GAME.TXT `@TUTORIAL1`～`@TUTORIAL19` 共 19 則，另有地圖編輯器 MAPEDIT.TXT `@HELP1`～`@HELP5` 共 5 則。
- 教學提示與一般對話框是同一個逐字印字常式、同一種木紋框；差別是印字期間顧問肖像壓在框上。

## 做法

1. 通用引擎（規格035／036）的模板來源加入 help 雙語清冊；`--tutorial-help-a` 開啟時首則仍由專屬欄位處理。
2. 木紋框正文不再以「印字期間其他寫入者與安全區重疊」為撤銷條件：逐點以最後寫入者重建印前底圖，只還原最後由改色常式寫下的像素，肖像像素保留原版印後值。
3. 以 Discoverer 英國開局為基礎，用探針逐步延長正常玩家路徑（登陸、建殖民地、殖民地畫面、歐洲港口、拓荒者、道路與開墾等），記錄各則提示的觸發步數與畫面。
4. 可觸發者做真 GUI 與中英同輸入驗證；無法在正常路徑觸發者（例如後期的皈依者、地圖編輯器說明）記錄原因。

## 退出條件

各則有正常路徑觸發證據與真 GUI／中英重播驗證，或記錄無法觸發的原因；驗證矩陣新增一列；全面回歸不退步。
