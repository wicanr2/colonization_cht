## 做法

1. **逐行清單引擎（規格036）：**沿用規格035 的逐字段落偵測，但以「行」為單位比對字典（MENU.TXT 項目、GAME.TXT 選項行、補充字串）；每行在原位擦字後畫中文，字色取原版觀測色，滑過重印時重新套用。同一機制也供 #46 的對話框選項列使用。
2. **對話框引擎擴充（規格035）：**允許 `^` 置中碼段落，置中行保持置中、其餘依框寬重排；字色與陰影依觀測色號選擇（木紋框 68／149／47，羊皮紙 0／242）。
3. **OPENING.EXE 的載入訊息：**不走 `0D21:00C6`，字串固定、顯示期間畫面靜止，改用規格034 的靜態指紋路徑，並以原文色號集合清字（深色木紋上的亮綠字）。
4. 版本字串與載入訊息不在既有語料內，補到可追溯的字典（檔名、位移、片段雜湊）。

## 退出條件

四處各有 RE 證據、規格、真 GUI 與中英同輸入驗證；無法在正常路徑觸發或無法安全覆蓋者記錄原因。
