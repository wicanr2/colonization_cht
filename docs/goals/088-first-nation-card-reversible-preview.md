## 玩家問題與範圍

第一張國家旗卡的 `ENGLAND:`／`Immigration` 已追到原始檔案與
原版畫布，畫面仍是英文。本輪先為這兩欄建立來源固定的繁中草稿與
可丟棄 Ebitengine 四倍畫布對照，量測原文墨跡、各欄字級、背景、
安全矩形及翻譯長度。不能因原版文字短，就直接沿用主選單24px、
難度卡片21／25px或國家頁左側38px。其他旗卡及整頁完成不在本輪
宣稱範圍；正式覆蓋仍由 READY 閘門決定。

## 執行與退出條件

1. 先推送本目標到已核對為 PRIVATE 的儲存庫。固定合法 DOS
   原版、隔離 dosgolem、真視窗16筆輸入、現有雙次冷啟動與無觀測
   控制收據；原版、字型及原始像素只在本機唯讀使用，所有分析、
   建置、畫面與測試在有界 Docker 容器。
2. 從已證實的 `NAMES.TXT:0x8EA`／`LABELS.TXT:0x8F2` 建立兩筆
   唯一 `draft` 譯文候選；保留原始檔案與片段 SHA-256，並核對
   Cubic 11 字形覆蓋。上方原版格式化時另加冒號，草稿必明記
   原文來源與畫面呈現的差別，不能把冒號改寫進原始鍵。
3. 以 dosgolem 原版印字前／後畫布與固定真視窗索引畫面，逐欄
   量出原版墨跡、底圖多色分布及不相交安全矩形。為兩欄分別
   測試中文字級／墨跡與內距；失配時只回退原文，不裁切或
   塗成單色。
4. 重用既有 Ebitengine 預覽機制生成原文控制與中文候選兩圖，
   由獨立驗證器檢查原版畫布四倍最近鄰、安全區外零差異、透明
   中文字模下逐像素恢復原背景及兩欄均有實際變化。圖像與含
   原版像素的 JSON 只留 `workplace/`；不更新正式截圖。
5. 更新規格021的 DRAFT 量測與下一輪 READY 缺口，更新
   `CONTEXT.md`、研究紀錄、工作歷程與唯一工作清單；推送私有
   儲存庫、回填對應 GitHub Issue。收尾核對原版素材未入 Git、
   檔案擁有權、誤建 `.md` 目錄與 Docker 清理狀態。

## 停止線

原型不是正式前端或玩家路徑中文驗收；本輪若未取得當次底圖、
字級或可逆性證據，保持 DRAFT 並明記缺口。即使原型通過，仍需
執行期逐欄背景／游標／按鍵／切場守門、READY 審查、真視窗
中英文同狀態及回退驗證，才可增加目前十四段正式中文顯示數。
