## 範圍與理由

現有正常玩家路徑由合法 DOS 原版冷啟動、主選單滑鼠選擇到難度頁；
第一、二張卡片各兩行已限定驗收，但尚未按「完成後點此」進入下一畫面。
24則 help 譯稿與其他大量雙語資料也尚無畫面命中。這輪優先延伸真實玩家
路徑，以原版輸出找下一個值得翻譯的訊息，不預設下一畫面就是殖民地、
國家選擇或說明頁。

## 工作與退出條件

1. 先推送本目標至私有儲存庫。核對原版檔案 SHA-256、隔離 dosgolem
   提交、既有12筆真視窗輸入及前端版本；原版輸入唯讀，所有分析與重播
   均在有界 Docker 容器。用同一難度頁狀態，測試原版完成區的滑鼠
   移入／按下／放開，並保留無點擊與只移入控制組。
2. 若能前進，以 dosgolem 連續重播與真 Ebitengine 視窗各驗一次，
   登錄輸入、步數、開檔、CPU、完整 RAM、原版索引畫面、色盤、時間及
   未縮放畫面；與同輸入無中文觀測的控制組比較。不得用 direct-entry、
   記憶體注入或不同初始狀態冒充正常玩家路徑。
3. 盤點新畫面玩家可見原文：先分動態輸出、烘入圖像與未知來源；對
   第一個可穩定重播的新動態訊息，追溯檔名／SHA-256／檔案位移、
   DOS 線性 RAM、原始實模式 CS:IP、輸出畫布差分與安全矩形。另以
   實際輸入檢查 help 是否可達；不能到達就明記缺口，不把24則譯稿
   計為已顯示。
4. 建立 DRAFT 規格與完成度分母；若來源、當次畫面、游標守門、
   中文字級與最長譯文都已證實，再審查限定 READY、製作可丟棄
   Ebitengine 中英預覽，最後才可能接正式輸出並用真視窗同狀態驗收。
   任何一項未知時維持英文，不猜補原版行為。
5. 更新目前脈絡、研究紀錄、工作歷程及相關 Issue，推送私有儲存庫。
   收尾核對原版素材未入 Git、產物 UID/GID 與 Docker 容器清理狀態。

## 停止線

這不是 remake；不修改原版 EXE、TXT、規則、滑鼠命中區、存檔或
玩家流程。Issue #28 的難度標題 A／B 版式仍待使用者視覺決定；
本輪不自行選版或更新含原版像素的私有截圖。新畫面或 help 若未具備
原版輸出與逐欄字級證據，不宣稱中文化完成。
