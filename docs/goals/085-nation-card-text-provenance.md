# 目標085：國家旗卡紅字的來源與畫面路徑

狀態：進行中；日期：2026-09-23。承接[目標084](084-nation-heading-runtime-guard.md)
及[規格020](../spec/020-nation-heading-overlay.md)；對應動態清冊
[Issue #7](https://github.com/wicanr2/colonization_cht/issues/7)、靜態清冊
[Issue #8](https://github.com/wicanr2/colonization_cht/issues/8)與正式覆蓋
[Issue #12](https://github.com/wicanr2/colonization_cht/issues/12)。

## 問題與範圍

已驗的國家選擇頁左側兩行現在能顯示「選擇／歐洲國家」，但被選中的
第一張旗卡上、下緣仍有紅色英文。此目標只追這兩處實際可見的字，
先判斷它們來自原版動態印字、靜態圖像，還是尚未證實的混合路徑。
不憑畫面猜文字內容、檔案鍵或覆蓋座標；也不把其他旗卡、完成提示
或 help 一併聲稱已定位。

## 工作與退出條件

1. 先將本目標推送到已確認為 PRIVATE 的儲存庫。固定合法 DOS 原版
   各檔 SHA-256、隔離 dosgolem 提交、現有16筆真視窗輸入及同輸入
   英文控制；原版唯讀，所有分析和重播在有界 Docker 容器中。
2. 從現有同狀態原版索引畫面量出兩處紅字的原始畫布候選矩形與色號，
   分開記錄「目前可見」和「原始印字前後差分」；旗幟圖案與外框不得
   被誤算成文字。若動態畫面事件無法證明，保留未知。
3. 以 dosgolem 的檔案讀取、原始呼叫點、文字來源與畫布寫入觀測建立
   可重播收據。動態路徑須閉合檔案位移或原始位元組 → RAM／格式化
   緩衝 → 實模式輸出 → 像素；靜態路徑須閉合圖像來源、版本指紋與
   當次畫布定位。各地址空間及推論等級分開標明。
4. 用兩次獨立冷啟動及同輸入無觀測控制組核對 CPU、完整 RAM、原版
   索引畫面、色盤與虛擬時間；建立負例或相鄰狀態，避免把先後發生
   誤稱為資料流。若證據足夠，只產生 DRAFT 規格與下一輪 READY
   所需反例清單；未經 READY 不修改正式覆蓋程式或增加已顯示段數。
5. 更新 `CONTEXT.md`、`RESEARCH-LOG.md`、`WORKLOG.md`、工作清單及
   對應 GitHub Issue，推送私有儲存庫；檢查原版素材、字型、畫面與
   研究收據均未誤入 Git，並核對檔案擁有權及 Docker 容器清理狀態。

## 停止線

不修改原版 EXE／TXT／圖像、RAM、遊戲規則、滑鼠命中區、存檔或
玩家流程。既有十四段限定中文顯示不因來源調查而增加。
[Issue #28](https://github.com/wicanr2/colonization_cht/issues/28) 的難度
標題版式為獨立視覺決策；使用者已選 A，正式實作與驗證由目標086
負責，不借本目標修改難度畫面。

## 已取得的限定證據（尚未達退出條件）

2026-09-23 的兩次獨立冷啟動收據與無觀測控制組，均以相同的16筆
真視窗輸入走到第一張國家旗卡。原版 `NATIONS.PIK` 開啟後，上、下
兩塊紅字區各有 `0D21:012C` 畫布寫入144／172點，並觀測到
`0D3A:0015` 來源讀取與 `0D21:00C6` 格式化字串讀取；因此這兩塊
可見紅字的當次繪製屬**動態文字**，不能只靠靜態圖塊替換。來源
候選為 `NAMES.TXT:0x8EA`／`LABELS.TXT:0x8F2`，但檔案載入至
RAM 的邊尚未閉合，不能升為正式覆蓋鍵或 READY 規格。
詳細的檔案雜湊、位址空間與收據見 [研究紀錄](../../RESEARCH-LOG.md)。
上述原版畫面與收據仍只在已忽略的 `workplace/`，沒有加入 Git。

本段只訂正本目標先前「動態／靜態未知」的暫定分類；尚未建立
相鄰狀態負例、完整原文檔案載入鏈、背景可逆補片與逐欄守門，
因此本目標仍是進行中。[Issue #28](https://github.com/wicanr2/colonization_cht/issues/28)
的 A 版決定已另由[目標086](086-difficulty-heading-centered-layout.md)處理。
