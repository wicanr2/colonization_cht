# 目標 034：完整開場畫面後的單次 Enter 正常路徑探測

狀態：completed<br>
日期：2026-09-21<br>
對應 Issue：[Issue #5](https://github.com/wicanr2/colonization_cht/issues/5)<br>
前置證據：[目標 024](024-first-screen-normal-input-observation.md)、[目標 033](033-ocean-label-post-copy-persistence.md)

## 目的

目標 024 已證明首畫面上的 BIOS Enter 使流程進入開場資產載入；目標 033 則固定了第一個完整 composite 畫面。
本輪從該畫面後的同一 state，比較「無輸入」與「一個 BIOS Enter」兩條正常玩家可用的路徑，找出是否進入新的
可見狀態、檔案載入或文字輸出觀測面。這是動態文字輸出追溯的輸入前沿，不是把靜態圖像當成文字常式。

## 執行項目

1. 以目標 033 的 #5,465,772 固定 state 為唯一起點，分別重播至同一絕對步數：控制組不送輸入；實驗組只在
   #5,465,773 起排入一個 BIOS 緩衝區 Enter。兩組不得沿用彼此的記憶體、檔案或輸入佇列。
2. 對兩組記錄鍵值實際取走位置、畫面雜湊／色號陣列、A000 寫入、DOS 檔案服務、字型 hook、B8000、主控台與
   未實作服務；必要時保存僅本機的終點 indexed frame／palette。結果必須以同一終點、同一 state 對照。
3. 若 Enter 造成狀態改變，追蹤第一個不同畫面或輸出觀測點的步數與原始定位；若沒有改變，明確區分「鍵未取走」
   與「已取走但窗口內無可見改變」。不得以單張畫面、資產檔名或內容猜測動態文字。
4. 回填收據、輸入、位址空間、推論等級與未解項至研究紀錄、現況、工作清單、Issue #5、工作歷程與 Git。無論
   結果，不建立動態文字 DRAFT、譯文、字型、覆蓋程式或原版衍生版控內容。

## 結果

- 控制組從第 #5,465,772 指令 state 連續執行至 #7,000,000，仍在 mode 13h；沒有鍵值取走、檔案開啟、主控台、
  B8000、全形／半形字型 hook 或未實作服務。其終點色號陣列 SHA-256 為
  `ff3b73f1e327e09549e6f347d59f1f227e139b63db20c317d8f5138423f20279`。
- 實驗組的單一 Enter 在 #5,465,827 由 `int16-AH00-bda` 取走，未到共同終點即於 #5,511,796 以離開碼
  `0x6C` 終止；#5,511,173 切換至 mode 03h。raw `0562:0394–0397` 為 `B4 4C CD 21`，前置暫存器
  `AX=4C6C`，故 `0562:0396` 是已證實的 DOS `AH=4Ch` 終止指令。
- Enter 組也沒有開啟新檔案、主控台輸出、B8000 或全形／半形字型 hook；唯一未實作服務是終止前的
  `int 21h AH=2Dh` 一次，尚未證實其語意或對退出分支的影響。mode 03h 後的 A000 傾印只是殘留，不被當成
  可見畫面或文字證據。
- 因此這個固定畫面上的單次 Enter 是 `OPENING.EXE` 的 confirmed 離開分支，而非已發現的動態文字路徑。
  後續須追溯哪個正式啟動器／父程序消費離開碼 `0x6C`，或以另一條正常入口進入遊戲；不建立 DRAFT／READY、
  譯文、字型或覆蓋程式。

## 停止線

- 只測一個已知可重播的 BIOS Enter；不盲注多鍵、掃描點擊、改寫記憶體、以 debug entry 繞過玩家流程，或將
  任何失敗／退出路徑解釋為遊戲語意。
- 控制組與實驗組的終點步數、state、觀測器與輸出格式必須一致；控制組靜止不能單獨證明 Enter 路徑成功。
- 即使發現新畫面，也不得把 A000 點陣、B8000 空值、檔名或文字外觀直接升格為動態印字／文字來源／中文安全矩形。
