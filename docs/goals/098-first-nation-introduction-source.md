# 目標098：首次國家介紹長文的來源與畫面證據

[目標096](096-player-name-prompt-runtime-guard.md)與

## 玩家問題與本輪範圍

從選國後姓名畫面按 Enter，已能在原版畫面看到 `FRANCE` 與介紹長文，
但標題和內文的固定來源、動態／靜態分類、印字順序、分段邊界、
實際安全矩形與後續翻頁條件仍未閉合。只靠一張畫面不能把既有
百科／help 譯稿猜作此處訊息鍵。本輪先建立從原始檔到 DOS 讀取、
RAM、原版輸出事件及320×200畫布的最小充分證據；來源不明則保持
原文，不把譯稿接入正式前端。

## 工作與退出條件

1. 先將本目標與 `CONTEXT.md` 入口推送已核對為 PRIVATE 的儲存庫。
   固定合法 DOS 輸入 SHA-256、十六筆正常玩家輸入、隔離
   `workplace/dosgolem` 提交及現有姓名頁真視窗控制收據。原版唯讀；
   分析、建置、測試與抓圖僅在限資源、無網路 Docker。含原版
   畫素及完整原文的中間物只留已忽略 `workplace/`。
2. 以 dosgolem 從冷啟動經主選單、難度、選國及姓名 Enter 正常路徑
   抵達首次國家介紹。雙次重播與無觀測控制核對 CPU、完整 RAM、
   原版索引、色盤、虛擬時間、開檔及畫面；不得以 direct-entry、
   記憶體改寫或 DOSBox 圖片替代正式原版收據。
3. 先在固定原始檔中查可見標題與長文候選，再追候選來源的 DOS
   讀取、20-bit線性 RAM、實模式 `CS:IP` 呼叫與畫布印字；
   逐項註明檔名與 SHA-256、位址空間、原始 bytes／偏移、工具版本、
   推論等級與反例。若長文不是單一檔案或多次重繪，依事件分段，
   不把相同可見字串誤當成已確認來源。
4. 用原版印前／印後索引畫布量標題、段落、框線、換行與頁尾的
   半開安全矩形及原版墨跡高度；測試至少保持不輸入與一個正常
   翻頁／離頁按鍵。若本輪無法閉合按鍵語意，只記具體缺口。
   翻譯與 Cubic 11 候選字級必須以各欄的原版幾何另驗；不套用
   姓名提示38px或難度標題34／38px。
5. 對已閉合的可見訊息建立 DRAFT 規格與可追溯繁中稿的入口；
   若原始分段／格式控制碼尚未確定，先只登錄鍵與缺口，不猜譯文
   或畫面分頁。只有證據審查至 READY 後才可另行接正式中文顯示，
   同狀態驗收前不增加十五段已驗數量。
6. 回填 `RESEARCH-LOG.md`、`CONTEXT.md`、`WORKLOG.md`、唯一工作清單
   與遠端 Issue #30，推送私有 repo；檢查原版素材未入 Git、輸出
   UID/GID、隔離 dosgolem 的 `upstream` push、誤建目錄與 Docker 容器。

## 停止線

不改原版 EXE、資料、玩家姓名、遊戲規則或存檔；不以現有長文
譯稿數量推論執行期覆蓋率。DRAFT 探針與可丟棄預覽不能進正式
玩家路徑，DOSBox 只能作補充。目標097的姓名欄顯示選擇獨立保持
待決；本輪不替使用者選 A 或 B。
