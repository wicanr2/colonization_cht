# 目標158：全遊戲 TXT 訊息分母（Issue #27 第四輪）

狀態：進行中；開始：2026-09-26。對應 [Issue #27](https://github.com/wicanr2/colonization_cht/issues/27)。

## 範圍

- 在 Docker 內解析原版全部 `*.TXT`，以段落標記（`@NAME`）與行切成訊息單位，每單位記檔名、位移、長度、片段 SHA-256。
- 分類：玩家可見文字、控制與資料行（純數字、座標、圖檔名、格式參數）、除錯或未使用段落（證據不足時標「未知」，不猜）。
- 與既有十份譯稿依位移範圍對照，得出：已抽取、已翻譯、未建檔的玩家可見單位數。
- 可提交摘要只含數量、檔名與鍵；含原文的明細只在 workplace。

## 退出條件

- `tools/text_inventory.py` 重跑得到相同報表；缺原版回 SKIP 77。
- 分母與覆蓋率寫入目標文件，未建檔單位清單可供後續批次翻譯。
