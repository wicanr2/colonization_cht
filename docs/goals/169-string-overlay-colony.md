# 目標169：通用字串覆蓋與殖民地畫面（Issue #44 第一部分）

狀態：完成；2026-09-28。對應 [Issue #44](https://github.com/wicanr2/colonization_cht/issues/44)，規格見[規格038](../spec/038-string-overlay-draft.md)。

## 已知

- 殖民地畫面的標題、港口欄、生產欄、貨物數量與 `Exit` 都由 `0D21:00C6` 以**連續讀取**印出：每串以 0 結尾，由 `0D21:012C` 上色，沒有陰影色（探針 `workplace/reports/goal169-colony/c2`）。這與海上狀態欄（規格032）同一種讀法，但規格032 只處理海上頂列與狀態欄兩個區域。
- 通用對話框引擎（規格035／036）只處理「字元與 0 交錯」的逐字讀法，不涵蓋連續字串。
- 目標167 的探勘 a7 在 1,047M 步建立 Jamestown 並進入殖民地畫面，1,053M 出現 `@TUTORIAL4`。
- 使用者 2026-09-28 決定：殖民地名稱等於 COLONY.TXT 預設名時顯示「中文（原名）」，玩家自訂名保持原樣。

## 範圍

1. 規格038：連續字串的通用覆蓋（偵測、逐串像素歸屬、字典與模板、字級量測、啟用與撤銷）。
2. 模板表 `text/string-templates.zh-Hant.tsv`：組合字串（殖民地標題、生產百分比等）的中文排列，每列附原版證據。
3. 殖民地畫面首屏字串中文化；海上狀態欄缺譯的地形名補進規格032 詞典。
4. 真 GUI 從冷啟動走到殖民地畫面（含 `@TUTORIAL4`），中英同輸入重播、反向對照、全面回歸。

## 退出條件

規格038 READY 並限定 CONFORMED；殖民地畫面首屏字串中文、缺譯者回原文並記錄；驗證矩陣新增一列且全 PASS。

## 停止線

殖民地畫面內的操作（點建築、移動殖民者、貨物面板）、歐洲港口、報告與百科是 #44 後續目標。地圖上的城名標籤不走 `0D21:012C`，另行取證。

- 真 GUI 建立 Jamestown，殖民地首屏與海上狀態欄字串中文，`@TUTORIAL4` 中文且關閉後殖民地字串自動恢復；中英原版狀態一致；兩個反向對照符合。檢查器 `tools/check_goal169_window.py` PASS，驗證矩陣新增 `colony-strings` 列。
