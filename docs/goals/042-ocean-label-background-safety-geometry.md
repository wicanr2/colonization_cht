# 目標 042：海洋標籤背景安全幾何

狀態：in_progress<br>
日期：2026-09-21<br>
對應 Issue：[Issue #8](https://github.com/wicanr2/colonization_cht/issues/8)<br>
前置證據：[目標 031](031-opening-full-frame-static-text-survey.md)、[目標 032](032-ocean-label-canvas-writer-provenance.md)、[目標 033](033-ocean-label-post-copy-persistence.md)

## 目的

`opening-map-ocean-label` 已有唯一的邏輯幾何來源：canvas／A000 的
`x∈[53,174)`、`y∈[49,61)`。靜態中文覆蓋必須先知道該文字是否位在可重建的均一背景上，及有限外框是否會碰到
其他圖像；可見文字外框本身不是安全矩形。

本輪在固定完整 composite state 只讀取未縮放 canvas 與同位置 A000 的色號，量化精確矩形、左右／上下有限外框與
色號／連通性。若背景不能由證據安全重建，結論只能是「尚不可覆蓋」，而不是擴大矩形或猜測填色。

## 執行項目

1. 從 #5,465,772 固定 state 唯讀傾印包含標籤與有限外框的 canvas 與 A000 rows；確認兩份同狀態色號逐位元組相同，
並保存 state、範圍、尺寸與 SHA-256。
2. 以固定的 `(x,y,w,h)` 資料表計算標籤矩形與四邊有限外框的色號集合、每列分布及非候選連通區；不靠縮放 PNG、
人眼或 OCR 推定座標。
3. 只判定「已證實可重建的背景」「強推論背景」或「不可安全覆蓋」；不製作中文、字型、清除遮罩、DRAFT／READY
   或修改原版／dosgolem。

## 結果

- 從固定 #5,465,772 state 的零指令 dump 取得 canvas `1C43:3840:6400` 與 A000 `A000:3840:6400`；兩份
  320×20 rows 逐位元組相同，SHA-256 均為
  `c13081ba2d6fbe514e6eae7b6b75eb27d1a0eddbca644ee759961f6d20746c51`。它們涵蓋邏輯 y=`45..64`，
  標籤唯一幾何仍是 `(x=53,y=49,w=121,h=12)`。
- **confirmed**：標籤矩形有 61 種色號，有限外框有 67 種，兩者共享 48 種。矩形內最常見的色號
  `136`／`173` 僅佔 `736`／`359` 個像素（共 1,452）；並非可直接重建的單色底。
- **confirmed（安全否定）**：以 `{136}`、`{173}` 或 `{136,173}` 分別視為背景時，非背景 4-連通區跨越標籤與外框
  的數量依序為 `10`、`1`、`19`（兩色集合最大跨界 component 是 183 pixels）。因此現有畫布色號無法將英文
  字形與相鄰地圖圖像安全隔離；沒有證據允許平面填色清除、擴大不透明矩形或生成遮罩。
- **unknown**：原文字形前的每像素背景、可逆清除策略、中文安全矩形、完整資產歸屬與任何中文排版。下一步必須找到
  獨立的 pre-text 背景證據或轉查其他候選；不能由本輪結果直接製作原型。
