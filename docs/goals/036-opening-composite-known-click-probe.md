# 目標 036：完整開場畫面上的已知中央左鍵路徑

狀態：completed<br>
日期：2026-09-21<br>
對應 Issue：[Issue #5](https://github.com/wicanr2/colonization_cht/issues/5)<br>
前置證據：[目標 024](024-first-screen-normal-input-observation.md)、[目標 033](033-ocean-label-post-copy-persistence.md)、[目標 034](034-opening-post-composite-enter-probe.md)、[目標 035](035-opening-exit-code-launcher-chain.md)

## 目的

目標 024 已確認較早的正常開場階段，中央 `(160,100)` 的單次左鍵與 BIOS Enter 都能使資產載入流程前進；
目標 034 則確認完整 composite 畫面後的單次 Enter 只會使 `OPENING.EXE` 結束。目標 035 排除了可觀測的
batch 父程序消費者。本輪只在目標 033 的固定完整畫面 state，測試這一個既有、已記錄的中央左鍵，確認它是否被
程式讀取、是否走向新的可見狀態或文字輸出觀測面。

## 執行項目

1. 從第 #5,465,772 指令的固定 state 以相同觀測器重跑無輸入控制組與實驗組；實驗組只在
   #5,465,773 排入 `(160,100)` 的左鍵，並以「首個滑鼠輪詢後放開」限制按住時間。兩組的原版輸入唯讀，
   不共用記憶體、輸入佇列或輸出檔。
2. 記錄滑鼠輪詢、按鍵實際讀取、首個控制流／畫面／模式／檔案服務差異，以及主控台、B8000、字型 hook 和
   未實作服務。若程式提前結束，保留終止步數與 raw 指令／暫存器；mode 改變後的 A000 殘留不可視為畫面。
3. 結果只能區分「未被讀取」、「已讀取但窗口內無可見差異」、「已讀取並進入可重現的新狀態」；不得從座標、
   影像外觀、資產名稱或退出碼猜測按鈕／場景／文字語意。
4. 不建立動態文字 DRAFT／READY、譯文、字型或覆蓋程式；若出現文字觀測，只建立下一個窄的證據目標。

## 結果

- 控制組從同一 state 執行 1,534,227 道指令至 #7,000,000，仍在 `0557:00B3` 的 mode 13h；共有 1,255 次
  滑鼠輪詢、沒有檔案開啟、主控台、B8000、全形／半形字型 hook 或未實作服務。lifecycle SHA-256 為
  `d0a8cd67143ac3be9aed7cf305657a77250d88333a9d1fb78a27b1fb008d1934`，終點 indexed frame SHA-256 為
  `ff3b73f1e327e09549e6f347d59f1f227e139b63db20c317d8f5138423f20279`。
- 實驗組在 #5,465,840 由 `int 33h AX=0003` 讀到注入的 `(160,100)`、按鍵 `01`；首個輪詢後放開，整條路徑
  只有這一次按下觀測。它在 #5,509,215 切至 mode 03h，#5,509,826 於 `0562:0396` 以
  `AH=4Ch, AL=6Ch` 終止，總共 44,053 道指令。這個 raw 終止位置／bytes 已在目標 034 以同一固定
  `OPENING.EXE` 雜湊確認；本輪 trace 也在呼叫前記錄 `AX=4C6C`。
- 實驗組沒有新檔案、主控台、B8000 或全形／半形字型 hook；終止前仍有一次未實作的
  `int 21h AH=2Dh`。其終點 A000 色號陣列（SHA-256
  `304ffd302045969ddad4a6c5e3c139a1af5f9f1bdbc1a060600b981ef26faeaf`）在 mode 03h 後是殘留，不能與
  控制組的較晚 mode 13h frame 比較或當作左鍵後可見畫面。
- 因此 `(160,100)` 是此完整開場 state 的 confirmed 輸入消費點，且會進入 `OPENING.EXE` 的退出路徑；
  不知道該點的畫面／按鈕語意，也沒有發現動態文字事件、文字來源、翻譯鍵或中文覆蓋資格。

## 停止線

- 僅使用目標 024 已記錄的單一 `(160,100)` 左鍵；不掃描其他座標、不重複點擊、不混入鍵盤輸入、不修改記憶體，
  也不以 debug entry 繞過正常輸入。
- 控制組不證明點擊分支成功；兩組都要記錄同一起點、預定終點、輸入與觀測器。提前結束只描述退出路徑。
- 沒有可回查原始定位的文字輸出事件，不得建立翻譯鍵、字型需求、中文安全矩形或任何覆蓋資格。
