# 目標086：依使用者選定 A 版完成難度標題排版

狀態：completed；日期：2026-09-23。承接[目標080](080-difficulty-heading-layout-prototype.md)、
[規格018](../spec/018-difficulty-heading-layout-draft.md)及已確認的
[Issue #28](https://github.com/wicanr2/colonization_cht/issues/28)。

## 已確認決定與範圍

使用者看過英文／目前中文／A／B 四格可丟棄對照，選定 A：
「選擇」34px、「難度」38px，兩行以原版共同中心線 x=230
（1280×800 四倍畫布）置中；排除 B 的各行左起點。
只修改這兩欄的中文字模與位置，不改難度卡片、完成提示、原版
滑鼠命中區、遊戲資料或規則。使用者另確認：同狀態驗證通過後
才更新私有成果截圖。

## 工作與退出條件

1. 先推送本目標。固定原版 SHA-256、隔離 dosgolem、目前 TSV、
   Cubic 11 字型及已驗九筆正常玩家輸入；重跑原版幾何／可丟棄
   A 版預覽的獨立驗證。所有建置、測試與抓圖在有界 Docker 容器。
2. 審查規格018：補上使用者決定、兩欄字模實測尺寸、位置、四倍
   安全矩形、至少4px內距、單行溢出與缺字回退、來源版本與狀態
   守門、英文控制及回歸測試。證據足夠才升限定 READY；否則維持
   DRAFT，不改正式前端。
3. 依 READY 從真 TSV 與固定字型重烘完整十四欄字模，只變更兩個
   標題欄位；前端核對各欄字級、實際墨跡尺寸與安全矩形後覆蓋。
   找不到譯文、重複鍵、缺字模、字模過長或來源不符均逐欄回退英文。
4. 以真 Ebitengine 視窗由冷啟動實際進入難度頁，與同輸入英文控制
   比較原版 CPU、完整 RAM、索引畫面、色盤、虛擬時間及中文安全區。
   另檢查游標遮擋、缺字模與錯版本、主選單五列、兩張卡片、國家頁
   兩行的同輸入回歸。全通過才標記規格018限定 CONFORMED、替換
   已授權私有儲存庫內的 `docs/screenshots/difficulty-zh.png`。
5. 更新 `CONTEXT.md`、`RESEARCH-LOG.md`、`WORKLOG.md`、工作清單與
   Issue #28，推送私有 repo；核對原版素材與本機字型不入 Git，
   Docker 容器、擁有權與工作樹乾淨。

## 停止線

不把選定 A 解讀成其他畫面共用 34／38px，也不宣稱原版字型
baseline 精確相同。若正式重播發現與可丟棄預覽不符，回到規格
證據審查，不以截圖或測試特例掩蓋差異。[目標085](085-nation-card-text-provenance.md)
的國家旗卡紅字來源調查獨立進行，未驗來源不得接入正式覆蓋。

## 完成結果

使用者確認的 A 版已依限定 READY 規格接入真 Ebitengine 視窗，
「選擇」34px／「難度」38px 都以四倍畫布 x=230 置中；其他
十二欄字模、卡片、完成提示及原版滑鼠命中區未改。
同輸入新舊版與英文控制的原版狀態相同，十五檢查點、逐欄回退與
錯版拒絕均通過；詳細數值及本機 PASS 收據指紋見
[規格018](../spec/018-difficulty-heading-layout-draft.md)。
通過後已替換既有私有[難度畫面截圖](../screenshots/difficulty-zh.png)，
沒有新增可公開原版素材。國家旗卡與 help 等工作繼續開放。
