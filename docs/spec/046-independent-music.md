# 規格046：原速音樂獨立播放

狀態：限定 CONFORMED。入口為[目標184](../goals/184-linux-player-regressions.md)。使用者於2026-10-05選擇「獨立播放」。

## 範圍與證據

播放器將音樂供給與主DOS執行速度分開。主DOS照常執行聲音命令、狀態查詢與音效，不修改CPU、記憶體、時鐘、輸入、規則或存檔。原始WAV仍記錄主DOS完整音訊。

輸入固定為 `OPENING.EXE` SHA-256 `3c08c4af3a709e155cb0ae043c9a2813b5cd34ed4bb0a1a3a0b12e7fa54d0d39`、`VICEROY.EXE` SHA-256 `a17ed64c27671e5e95236e54a7ddc85803a96ba822fbed05e1dad34d3917e2e3`、`PSOUND.COL` SHA-256 `8d5069fab621abfa5a4df4071612aa0d9f159c0907e51f0b1a193b73fa8b5c87`。原始檔唯讀。聲音驅動與曲譜不轉存進公開封包。

證據位於 `workplace/reports/goal184-linux/music-independent/`。工具為dosgolem `c83740bc5fcb2f2d8f2afb5d57cee6e92bd12f75`、Go1.26.7與IDA Pro9.4。`ida-driver.json`、`ida-music-api.json` 記錄輸入SHA與指令；IDA二進位載入EA是MZ body offset，執行定位為載入段的CS:IP。MZ header為512位元組，兩種位址不可混用。

## 接入契約

1. 第二台私用DOS只初始化原版驅動，再呼叫原版 `0B18` 與 `0BF9`。正式播放器按需求產生音訊；主DOS觀測只讀overlay與堆疊，不等待音訊合成，不回寫查詢結果。
2. 初始化後以原版命令0停止聲音。第一個實際命令到達才起曲。忽略查詢8；按順序轉送原版其他已驗命令範圍 `0..7`、`20h..3Fh`、`40h..5Dh`、`8020h..8026h`，保留參數。未知命令記錄錯誤並回退原播放，不猜測。
3. 停止、暫停、恢復、淡出與曲譜循環全部交由原版驅動。不得人工循環短曲、挑選背景樂或改寫曲譜。重載驅動時在私用側送命令0，避免上一段音樂殘留。
4. 兩台DOS彼此獨立。第二台只執行聲音API，沒有VGA或IRQ遊戲執行。單次API有指令上限；失敗記錄原因並回退主DOS原音訊。曲譜初始化、長度與結束不控制主DOS。
5. 主DOS的數位音效仍以原取樣時刻、原DMA與DSP路徑產生。dosgolem提供可選數位音訊分流：每幀只取一次SB sample，另外保存SB-only立體聲，原混音逐位元組不變；預設不啟用。FM音效由原命令在私用驅動播放，保留原始選擇與音色。
6. 獨立OPL與主DOS數位音效分別換算為48kHz，逐取樣相加並限幅。獨立OPL按播放需求產生；主DOS數位音效保留既有斷流淡入淡出。音樂供給、數位音效缺樣、丟棄、命令與錯誤各自記錄。
7. 命令佇列有界且不可阻塞主DOS。溢位記錄錯誤並回退。API合成及佇列只由播放讀取者消費。關窗關閉播放器與第二台DOS檔案；不留下執行緒或容器。
8. 音訊關閉時不啟動第二台DOS。版本不符時拒絕獨立播放，記錄原因並沿用原音訊。所有公開包只含播放器程式與既有合法中文化資料，原驅動從使用者資料讀取。

## 驗收與停止線

- 私用原型先驗原版暫存器音符序列、90秒原速供給、正常切曲、停止／暫停／恢復與非靜音。
- 通用分流驗證SB-only取樣、限幅、開關、原混音全等，不能額外讀取DMA。
- 正常玩家輸入的新版與舊版CPU、1MiB RAM、事件、索引、色盤、最終中文PNG及主DOS原始WAV全等。同一時區、原始檔時間及輸入。
- 以10ms單調時鐘消費者量測至少60秒播放。音樂供給不可缺樣，讀取必須快於需求；報告讀取延誤與數位音效缺樣，不把靜音補齊當音樂成功。
- Linux正常GUI與Wine抽測切曲及關窗。macOS只作建置與封包檢查，真機和音效卡實聽另列限制。

READY審查及正式驗證完成後追加本頁。原型性能不等於人耳驗收，主DOS全等也不等於獨立播放逐波形parity。

## READY審查，2026-10-05

開場曲90秒用7.706秒產生，主選單曲90秒用2.089秒產生；前者最後一秒仍非靜音，後者第55秒由原版驅動自然結束，沒有人工循環。停止初始化音樂後重新送命令34h，前111筆OPL bank／register／value序列與正常原版開場完全相同；相位與wall-clock分開記錄，不宣稱波形全等。曲譜及聲音命令仍由原版驅動執行，未重實作譜格式。

`trace-run-v2`與`trace-run-v3`的RAM、CPU終態、索引、色盤、中文PNG及原始WAV全等。驅動API、查詢排除與更新節拍足以描述本輪輸入輸出。授權依上述契約接入，剩餘正常GUI、實際時間消費與音效分流驗證是實作驗收。未觀測曲目語意不自行命名；只轉送固定版本原版API。

## 限定CONFORMED，2026-10-05

正式接線、原版控制及全部支援命令範圍的私用驅動測試、通用SB分流測試、65秒分塊串流、Go測試與go vet通過。第600M輪36位元組偶發缺樣的收據保留；以實際已提供取樣續接後，第800M輪83.892秒需求16106880位元組、音樂缺樣0、丟棄0，下一首22h,2也由原版第679135514步正常選曲。最長Read12.610ms、消費者延誤50ms，沿既有100ms播放器緩衝。

原版有限曲目結束後等待主DOS下一首，本輪59.0～71.1秒空白約12秒；不是供給缺樣，也沒有人工循環。數位音效缺樣2846960位元組保持可見，這條路徑沒有改成獨立播放。初始化、停止、曲尾、尚未到達下一首指令與播放供給不足分開解讀。
