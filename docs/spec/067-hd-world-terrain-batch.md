位址採dosgolem執行期segment:offset與線性RAM。
入口`0D46:000A`，AX為原ordinal加一；暫存畫布`0x3c500`、主畫布`0x2cae0`。
轉送與RAM還原只接受`0CBA:00CA`及16位元組
`f3a503f3790c81ee00808cd981c10008`，兩個byte各自驗證DS:SI與ES:DI及界限。
游標反向舊新值配對沿`0B68:051C`與已驗一般游標指紋，不以相同顏色猜來源。
個別來源遠指標、編碼、索引及逐寫雜湊待本批收據附表。

## READY前的必要結果

1. 逐來源驗證完整繪製、透明底圖、矩形外保持與暫存到主畫布的資料鏈。
2. 逐來源列出RAM保存、RAM還原及游標還原正向例；沒有正向例時保留限制。
3. 29份模型與既有R61逐byte相同；正常VGA中的可見來源另行確認。
4. 來源錯件、程式碼錯件、未知同值後畫及過期RAM身分反例必須拒絕。
5. 生成候選依原版安全遮罩驗證幾何、透明度、位置與合成像素，先做可丟棄原型。
6. 記錄候選來源、原PNG雜湊、筆觸、比例及回退策略，再審查為READY。

正式接線後才驗五語切換、正常GUI、存退讀與四側原版狀態／音訊／存檔一致性。
綠色來源模型不等於HD已完成。原版索引、色盤、圖像與暫存只留本機；公開資料只含程式與定位metadata。
