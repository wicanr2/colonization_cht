## 文字幾何與本機字模

使用者已選標題 A／34px，排除38px B；原版墨跡高8邏輯像素、完整寫入 bbox 高9像素，四倍後約32／36px。固定 `Cubic_11.ttf` SHA-256 `8de9c249b92bc414cb73f09ddb76c7cb327edb3907b638f0d0bd22691237fd5c`，現行 TSV `GAME.TXT:0x000004CD` 的真譯文烘得實際字模222×32px。四倍安全矩形 `[260,176,1012,236)`；前景半開框 `[268,188,490,220)`，色號68；陰影 `[272,192,494,224)`，色號47。兩者有內距，左側核取圖示不在標題安全區；原版印前安全區含10種底色，不可填單色矩形。標題無 `~` 快捷鍵，不改八列快捷鍵政策。

字模 JSON 只在本機由真 TSV 與固定 TTF 產生；正式程式核對候選鍵、來源位移、原始 bytes／來源 SHA、譯文 SHA、整份 TSV SHA、字型 SHA、34px、222×32尺寸與 Alpha長度。缺字、缺鍵、重複鍵、錯字級、控制碼或溢出即保留英文並記錄原因。標題固定單行，不換行、不截斷、不縮放；未來改譯文必須重新量測並審查，不能靠畫筆裁切。

## 執行期狀態與失敗即回退

1. `idle`：只有明示啟用且檔案版本、譯文與字模均有效才觀測。於 `0D21:00C6`、`SS:BX` 指向線性 `0x2AC78`、原版首字節正確、mode13h、**印前標題安全區** SHA `358729d7…` 與上述證據一致時，捕捉**當次**印前多色底圖，記錄開檔數並進入 `reading`。視窗外整張畫布可因正常玩家歷程不同；單張完成畫面、預讀文字或同文重出現仍不能建立權杖。
2. `reading`：依序核對16字元與16個交錯零位的32次 `SS:BX` 讀取；同期間只接受 `0D21:012C` 在標題安全區的319筆已驗改色、bbox與68／47／128色數。錯字、錯位址、錯寫入者、越界、超數或別的印字事件，撤銷本次權杖且畫面留英文；不寫原版記憶體。
3. `waiting-screen`：讀字與畫布改色齊備後，當次原版底層**標題安全區**必須匹配印後 SHA `4cc2db…`；最多等待2,000,000模擬指令，直到同幀實際 VGA標題安全區與當次印後畫布逐點相同。底層先成的那一幀仍留英文。逾時、mode／原版開檔變化或離窗即撤銷；2M只是本轉譯層保守上限，不是原版時序常數。
4. `active`：從當次印前與印後建立 `overlay.Patch`，每幀再核對 mode、開檔、底層及真 VGA標題安全區、字模與游標。當幀 `Mouse` 16×16矩形與中文前景／陰影區的原版對應範圍相交、按鈕按住或 VGA局部暫時不同時，該幀保留英文；**底層**標題區變化或 ESC離窗永久撤銷權杖。游標造成的暫時 VGA差異不得誤作永久離窗，移走後只有同一權杖且 VGA重合才可恢復中文。色盤可以因原版其他圖案循環而變，中文字與陰影每幀使用當時 DAC 的68／47色，不以歷史整份 DAC雜湊錯殺安全畫格。
5. `expired`：清掉補片與當次底圖；只有新的完整來源及輸出事件可回 `reading`。所有撤銷與保留英文原因要可在收據辨識。前端不得攔截或改寫原版輸入。

以上狀態機、2M上限與游標保守回退是輸出層**設計契約**；固定路徑讀字、畫布、VGA及ESC時序是**已證實**原版事實。沒有遊戲資料格式、規則或存檔副作用。
