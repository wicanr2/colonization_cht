## 可丟棄原型契約（不是正式執行路徑）

- 譯文唯一來源為 UTF-8 TSV 草稿，原文不回寫遊戲；此次只用已觀測第一列。
- 讀取呼叫前／後 canvas 差異，要求恰為已確認的文字範圍；只恢復這些文字像素的原始背景。
- 完成事件、原版版本、來源 bytes、預期整張索引畫面及色盤須吻合；不符保留原圖並記錄原因。
- 4 倍最近鄰放大原版，中文安全矩形暫採邏輯 `[86,107,232,114)` 的放大座標。
  以實際字型量測雙軸，超長單行採刪減尾字加省略號；連省略號也放不下就保留原文。
- 只在本機用 Cubic 11 候選製作原型，不散布字型，也不沿用 psychic-war 的倚天授權決定。
  字型 SHA-256 `8de9c249b92bc414cb73f09ddb76c7cb327edb3907b638f0d0bd22691237fd5c`。
- 必測關閉中文、缺譯、缺字、版本錯誤、畫面錯誤／切場、事件未完成與長譯文；
  回退輸出等於原版放大圖。中文只改輸出副本，不改快照或遊戲記憶體。

## 尚未 READY 的原因

字型、字級、譯文與版面需使用者看原型後確認。持續播放中的游標、反白、重繪、場景失效與
正式通用 xlate API 仍需窄規格及工程測試；不得把這支離線原型宣稱可互動中文化。
後續來源鍵候選應包含原版雜湊、原始檔位移、印字入口／caller、字串及繪製情境，
不能只有文字內容或固定座標。其他選項尚未完成動態驗收。

## 候選資料模型（非正式契約）

| 資料 | 候選欄位／用途 |
|---|---|
| 來源識別 | executable SHA、source file SHA、byte offset、byte length、來源片段 SHA。 |
| 輸出情境 | runtime entry、caller return、來源 far pointer、字串終止、繪圖參數及字型情境。 |
| 譯文 | UTF-8 TSV 的候選參照；整則訊息替換，不按原文／譯文字元數一對一配對。 |
| 幾何 | 原文字墨跡遮罩、印字前背景色號、獨立中文安全矩形、縮放、字級、溢出策略。 |
| 生命週期 | 完成事件、適用場景指紋、失效事件；只有命中且譯文／字型完整才覆蓋。 |
| 回退 | 原圖不變並記錄缺譯／缺字／版本／事件／場景失配原因；不得讓文字消失。 |
