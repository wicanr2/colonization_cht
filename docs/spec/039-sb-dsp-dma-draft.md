# 規格039：Sound Blaster DSP 數位音效

狀態：READY（2026-09-30；依據為公開硬體規格與已觀測的初始化序列，未知項只涉及本遊戲的使用方式，不影響通用能力）；DRAFT 2026-09-30（[目標175](../goals/175-sb-digital-audio.md)，[Issue #48](https://github.com/wicanr2/colonization_cht/issues/48)）。本規格授權的是 dosgolem 真實模式機器的通用能力，不含本遊戲位址；本遊戲的證據只用來選擇範圍與驗收。

## 硬體契約（公開資料：Intel 8237A、Creative Sound Blaster Pro 硬體規格）

1. **8237 DMA 通道 1**：0x02 位址、0x03 計數（先低後高，由 0x0C 清正反器）、0x83 頁、0x0A 單一遮罩（bit2 為設定，bits0–1 為通道）、0x0B 模式（bits0–1 通道，bits2–3 傳輸型式，bit4 自動重載，bit5 遞減）、0x0D 主清除、0x0F 全遮罩、0x08 狀態（讀取清除 TC 位元）。讀 0x02／0x03 回傳目前位址與剩餘計數（先低後高）。計數寫入值為「位元組數 − 1」。只實作通道 1；其他通道的寫入只記錄。
2. **DSP 播放**：0x40 時間常數（取樣率 = 1,000,000 ÷ (256 − TC)）、0x41 輸出取樣率（高位先）、0x14 八位元單次 DMA（長度 − 1，先低後高）、0x48 設定區塊大小＋0x1C 八位元自動重載 DMA、0xD0 暫停、0xD4 繼續、0xDA 結束自動重載、0xD1／0xD3 喇叭開／關。
3. **IRQ**：每傳完一個 DSP 區塊（單次為整段、自動重載為每個區塊），DSP 設 IRQ 掛起並向主 8259 送 IRQ7（向量 0x0F）；主 PIC 遮罩（0x21 bit7）與 IF 同 IRQ0 的派送規則。讀 0x22E 清除 DSP 的 IRQ 掛起。混音器 0x80 回 IRQ 設定（4＝IRQ7）、0x81 回 DMA 設定（0x22）、0x82 bit0 為八位元 DMA IRQ 掛起。
4. **終點**：單次 DMA 傳完後 8237 通道 1 設 TC 並遮罩；自動重載模式從基底位址與計數重新開始。

## 設計

1. **選用：**`Machine.EnableSBDigital()` 開啟；預設關閉，關閉時埠行為、原版狀態與既有版本逐位元組相同。只在 `SetSoundBlasterPro(true)` 之下有效。
2. **時間基準：**與 OPL 合成相同的指令數時鐘。DSP 播放從第 S0 道指令開始，到第 S 道指令時已傳送的位元組數為
   `b(S) = ⌊(S − S0) × num × 264 × calibrationDivisor ÷ (den × DefaultIRQ0Every × 315,000,000)⌋`，
   其中 num／den 是 DSP 取樣率（時間常數為 1,000,000／(256 − TC)，0x41 為 rate／1）。區塊傳完的指令數以同式反推（無條件進位），排入每步檢查。
3. **讀取記憶體：**已到期的位元組在每次計時器中斷、每次 `FlushAudio` 與區塊結束時從「目前頁＋位址」逐段讀出並推進 8237 位址與計數；程式在播放中改寫尚未讀到的位置，會反映在輸出上（誤差上限一個計時器節拍）。
4. **輸出：**有 OPL 合成時，每個 OPL 輸出取樣 j 換算其指令數 S_j，取當下正在播放的 DSP 位元組 u（未開喇叭、暫停或沒有播放時為靜音），以 (u − 128) × 64 加到左右兩聲道後截斷到 int16。沒有 OPL 合成時不產生輸出（前端必須先開 OPL 合成）。增益 64 是暫定值，音量平衡屬 #49。
5. **快照：**DMA 與 DSP 播放狀態不進快照；從快照還原後播放中斷（與 OPL 合成相同的限制）。

## 驗收（READY 前確認，CONFORMED 時執行）

1. 預設關閉：dosgolem `go test ./...` 全過；本專案既有驗證矩陣重跑結果不變。
2. 單元測試：固定埠序列下，單次 DMA 的完成指令數、IRQ7 派送、0x03 讀回剩餘計數、0x08 TC、自動重載的區塊 IRQ、0xD0／0xD4 暫停與繼續、輸出取樣值與位置。
3. 本遊戲取證：開啟後初始化 DMA 測試收到 IRQ；記錄之後的 DSP 播放（步數、取樣率、長度、來源位址），確認是否來自 `COLDIG.BIN` 的內容。
4. 決定性：同一輸入兩次 WAV 逐位元組相同。

## 取證結果（目標175）

- **初始化：**開啟後兩次初始化的 5 位元組 DMA 測試都收到 IRQ7，驅動隨即送 0xD1 開喇叭（confirmed，探針 `workplace/reports/goal175-sb/dig.json`）。
- **播放：**目標170／171／174 三條真 GUI 路徑在建立殖民地的木刻畫面（約 9.52 億步）都播放同一段取樣：先單次 2,593 位元組，接著在實體位址 0xD0000／0xD2000 兩個 8 KB 緩衝輪流以單次 DMA 串流 7 塊，最後 802 位元組；共 60,739 位元組，時間常數對應 10,989 Hz，約 5.5 秒。只用 0x14 單次 DMA，未見自動重載與高速模式（confirmed，`p170.json`、`p171.json`、`p174.json`）。
- **來源：**各塊開頭 64 位元組與 `COLDIG.BIN` 位移 0x5F5DF、0x60000、0x62000 逐位元組相同，連續不斷；`COLDIG.BIN` 從第 0 個位元組起就是無號 8 位元 PCM，沒有檔頭（confirmed）。0xD000 段是 EMS 頁框（強推論：驅動經 EMS 分段搬入）。
- **其他事件：**到 11 億步的三條路徑只在建城時播放；戰爭、原住民等特定局勢是否有其他取樣未觀測。

## 驗收結果

- **預設關閉：**以舊版 dosgolem（`a3a5609`）與新版各跑同一輸入到 7.2 億步，狀態雜湊相同（`56ba6d59…`）；dosgolem `go test ./...` 全過。
- **單元測試：**`internal/machine/sb_digital_test.go` 六項全過（單次 DMA、IRQ7 派送、自動重載、暫停繼續、混音輸出、未開啟不變）。
- **決定性：**同一輸入開啟數位音效兩次，WAV 逐位元組相同（18,888,584 位元組）。
- **音量：**播放期間每 2 秒 RMS 約 5,200～5,800、峰值約 13,200，播放前約 1,500，無削波。
- **前端不變：**新前端旗標關閉時重播目標174 路徑，終點狀態、48 個檢查點、完整記憶體與 47 張截圖都與既有收據相同。
- **dosgolem：**隔離副本本地分支 `colonization-audio` 提交 `b0bf259`（未推送），規格 `docs/spec/197-sb-dsp-dma-digital-audio.md`。
