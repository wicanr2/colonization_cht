## 原型驗證與 READY 前停止線

同狀態英文控制 PNG 與既有 dosgolem 英文難度頁圖逐像素相同；目前版原型
兩個標題安全區亦與既有真視窗中文版逐像素相同。A、B、目前版各自相對
英文控制，只在規格014兩個標題安全矩形內變化，變更像素分別為7,402、
7,539、6,732。原型僅組合離線畫面，不執行遊戲，不是新一輪 CPU／RAM
同狀態或真視窗玩家路徑驗收。

取得使用者選版後，才可將選定的逐欄字級、水平定位及回退條件寫成 READY；
再由同一份 TSV 生成逐欄字模，修改正式 `tools/live_menu.go`，重播正常玩家
路徑與英文控制，比對原版 CPU／RAM／索引畫面／色盤、Ebitengine 輸出、
游標入標題安全區與缺字模回退。未通過前不得更新既有私有截圖、宣稱新
CONFORMED 或關閉 Issue #28。
