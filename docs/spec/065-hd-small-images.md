## 隔離原型契約

- 31來源共用一個群組、一次0至0x9FFFF寫入觀測及一次指令邊界檢查。
  原版EXE、遊戲規則、輸入、資料、色盤、RAM與存檔不寫入。
- 入口0D46:000A原始12bytes為c828000052535057568b4702。
  核對AX原版序號加一、堆疊、描述子[200,320,0,0x2CAE]、完整來源指紋及未裁切目的矩形。
  返回須有原堆疊所定CS:IP、SP加10及100000步內完成。
- 三個已驗寫入端0D46:0181、01B4、01D2沿來源索引與R49的原碼；
  每個不透明局部像素恰寫一次，局部位移／色號序列SHA-256全同後才建立來源身分。
  透明點、重複、錯碼、超界、逾時或重入均不授予新來源。
- 一般游標只接受既有256bytes指紋及0B68:051C原碼，逐byte反向舊／新值配對後才還原。
  未知游標、後畫及同值寫入撤銷來源，不能按同色或相似圖像恢復。
- RAM沿R51的0CBA:00CA原碼與逐byte來源鏈，只接受主畫布至一般RAM保存及該RAM回主畫布。
  排除暫存畫布0x3C500至0x3C500+64000、VGA及越界／段落回繞。
  不接受主畫布直接複製、RAM至RAM或0C9F同碼；任何未知RAM寫入含同值都撤銷。
- 局部位置及來源槽位不由游標座標猜測；每格保存來源槽、局部位置與當次原版色號。
  只有當前色號仍等於來源且整體游標／畫布守門通過時，可在四倍畫布繪圖。
- 沿已定稿精細像素風。PNG與alpha原樣保存；alpha128只量內容矩形，合成仍取原RGBA。
  依原版不透明外框與像素中心最近鄰對應候選內容，變動只限有效來源的4×4區塊。
  原版模式逐像素保持，文字依已確認五語契約在圖像後繪製，原版游標最後還原。

1. 群組原型的49點來源身分與R51獨立模型相同；420次呼叫、保存／還原與游標統計逐項核對。
2. 測試真正原版來源、錯來源／幾何／寫入／返回、未知同值覆寫與過期RAM；缺合法原版明確skip。
3. 五語正常GUI經讀檔、進城、懸停、切換、存檔返回及離城；實際畫面、游標與來源外像素核對。
4. 實際GUI輸入於原型、唯讀觀測、正式基準及原版控制重播，完整狀態、音訊與存檔一致。
5. 候選畫質、透明輪廓、缺件／恢復、效能及正式來源／封裝另驗。

原型通過仍不直接成為正式程式；證據審查後才將足夠的來源與素材契約標READY，
正式接線及同狀態驗證後限定CONFORMED。未驗分支與其他圖像保持未知，不以來源清冊數當作完成比例。
