若真 TSV 缺鍵／重複鍵、來源指紋錯、字模缺失／尺寸變長、舊底圖、

原版兩行均為單行；本限定譯文不換行或截斷，任一未來譯文越界須

baseline 仍未知，採已量到的墨跡頂列與中心線近似，不宣稱精確基線對拍。

## 正式實作與 CONFORMED 閘門

若正式接線，兩行必須各以固定原版版本、`NATIONS.PIK` 已開啟、
唯一且來源指紋吻合的 TSV、原版 `0D3A:0015` 來源讀取及 NUL、

建立可逆補片。每幀須核對原版索引像素，游標或按鍵遮擋時逐欄
回退原文；缺譯／重複鍵、字模缺失／變長、舊底圖、場景切換或
檔案雜湊不符一律失敗即關閉。中文只疊在四倍 RGBA 畫布；

## 權利與停止線

原版檔案、未縮放索引、原始畫布、本機字型及含原版像素的視窗圖
都留在 gitignore 的 `workplace/`；本規格只提交程式、位址、譯文
來源鍵與證據摘要。它不修改原版資料，也不替使用者決定難度頁
Issue #28 的視覺 A／B 版式。受控 F1 注入於此國家選擇頁至80M步
沒有新增開檔或畫面變更，僅證明這個固定場景／輸入的反例；
不能推論 help 在其他畫面不可達，也不能把24則 help 譯稿算作已顯示。
