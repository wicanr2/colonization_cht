## 可丟棄視覺與游標反例

固定來源、真 TSV、字型與兩行印字前畫布組成的本機預覽
`nation-preview.json` SHA-256
`6d530c7164df76ac4ab923bad296df3823299b77feb76a64441a6f017748efe7`。
Ebitengine 英文控制圖等於原版索引／色盤四倍最近鄰；中文圖只在
兩個安全矩形分別變更2,610／5,502個輸出像素，透明字模下恢復
原始木紋；`tools/verify_card_preview.py` 收據為 PASS。此圖是原型，
不是正式遊戲前端或新增已驗收中文段數，含原版像素只留本機。

游標在 `(55,40)` 時原版索引畫面於第一／二行安全區各變更24／37點；
在 `(55,53)` 時第一行零變更、第二行23點。兩者底層文字畫布
均不變，移開後原版索引畫面逐位元組回到基準。這證明游標可遮住
原文，不證明所有游標外形的精確外包。

## 待 READY 的執行期契約與驗收

若正式接線，兩行必須各以固定原版版本、`NATIONS.PIK` 已開啟、
唯一且來源指紋吻合的 TSV、原版 `0D3A:0015` 來源讀取及 NUL、
`0D21:00C6` 格式化字節、當次印字前後全畫布差分與上述點數／bbox
建立可逆補片。每幀須核對原版索引像素，游標或按鍵遮擋時逐欄
回退原文；缺譯／重複鍵、字模缺失／變長、舊底圖、場景切換或
檔案雜湊不符一律失敗即關閉。中文只疊在四倍 RGBA 畫布；
原版 RAM、索引畫面、色盤、輸入、規則與存檔不得變。

READY 前尚需以可丟棄執行期守門確認：同一真玩家路徑的當次背景
可回填、兩行 patch 不會互相借用、游標／按鍵進出沒有殘留中文。
CONFORMED 前再做真 Ebitengine 視窗中文與同輸入英文控制、真 TSV
兩欄缺鍵／重複鍵、游標反例、錯版本拒絕、原有十二段回歸及安全區外
逐像素不變。未達前兩行均維持英文；[規格013](013-window-prototype.md)
目前只支援 Enter 與滑鼠，尚未提供玩家可按 F1 的完整鍵盤前端。

## 權利與停止線

原版檔案、未縮放索引、原始畫布、本機字型及含原版像素的視窗圖
都留在 gitignore 的 `workplace/`；本規格只提交程式、位址、譯文
來源鍵與證據摘要。它不修改原版資料，也不替使用者決定難度頁
Issue #28 的視覺 A／B 版式。受控 F1 注入於此國家選擇頁至80M步
沒有新增開檔或畫面變更，僅證明這個固定場景／輸入的反例；
不能推論 help 在其他畫面不可達，也不能把24則 help 譯稿算作已顯示。
