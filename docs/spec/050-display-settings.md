# 畫面外顯示設定與暫停

狀態：READY。僅授權前端設定狀態、輸入隔離與音訊暫停；不授權新的譯文包或 HD 合成器。

工作入口：[目標186](../goals/186-display-settings-and-gameplay-video.md)與
[Issue #62](https://github.com/wicanr2/colonization_cht/issues/62)。

## 決定與證據

使用者於2026-10-11確認畫面外設定列，可在遊玩中切換，開啟時暫停，關閉並放開
按鍵後恢復，不占原版快捷鍵。選定的操作原型位於本機
`workplace/reports/goal185-player-experience/display-settings-20261010/index.html`。
原型只證明操作選擇，不能當作原版執行證據。

| 等級 | 可回查事實 |
|---|---|
| confirmed | [window_prototype.go](../../tools/window_prototype.go)的`Update`是前端送入鍵鼠與推進主 DOS 指令的入口，每次最多200,000道指令。原版畫布1280×800，滑鼠座標除以四映回320×200。 |
| confirmed | 同檔的`release`會送出原版滑鼠放開事件。因此設定列不能直接呼叫它來截斷仍在遊戲內的拖曳。 |
| confirmed | 原版鍵盤只接收按下事件，實體鍵放開由前端觀察。開關設定的按鍵與文字不得進入原版輸入佇列。 |
| confirmed | [music_playback.go](../../tools/music_playback.go)的`Read`會推進獨立音樂 DOS；只停主機器指令不足以暫停音樂。 |
| 使用者決定 | 五語為`zh-Hant`、`zh-Hans`、`ja`、`ko`、`en`；圖像模式為原版與HD，與語言分開。英文使用原版字體，其他語言的保留英數使用該語言字型。 |

本規格沒有新增原版攔截點。位址空間、原始檔指紋與原版觀測仍沿用
[規格013](013-window-prototype.md)、[規格024](024-window-keyboard-input.md)、
[規格040](040-frontend-audio.md)及[規格046](046-independent-music.md)。
程式碼位置是前端 Go 來源行號，不能當作原版 CS:IP。

## 狀態與輸入契約

| 狀態 | 原版與前端行為 |
|---|---|
| 遊玩 | 沿用原版鍵鼠與指令推進。只有在原版沒有按住滑鼠按鈕時，才接受設定列的新按下。拖曳經過設定列不開啟設定。 |
| 等待開啟按鍵放開 | 立即停止主 DOS 指令與音訊讀取；保留已進入 DOS 的輸入。不送合成放開事件，不處理設定選項，等實體按鍵與滑鼠全部放開。 |
| 編輯設定 | 前端獨占鍵盤、滑鼠、滾輪、Escape與文字輸入；不呼叫原版輸入函式或`Step`。草稿與目前生效設定分開。 |
| 等待恢復按鍵放開 | 已取消或套用，原版仍停止。等實體按鍵與滑鼠全部放開後，於下一個Update邊界恢復，避免按鍵或點擊穿透。 |

開啟時複製生效設定到草稿。取消不改生效設定。套用先檢查語言與圖像模式，
再由顯示後端完整驗證並交換顯示資料；失敗保留原設定、草稿與面板，顯示原因。
成功後更新生效設定並等待放開。切換不重啟 DOS、不送假按鍵、不改 RAM、VGA、
色盤、亂數、遊戲資料或存檔。不從字型存在推論譯文包已完成。

設定列位於遊戲區外。遊戲區仍為1280×800，座標轉換先扣除設定列高度。
設定列高度屬前端版面，原型48px可作實作起點；不改原版320×200命中範圍。
顯示設定保存與語言包格式另立契約，本規格不先定原版資料格式。

## 音訊契約

暫停先在播放讀取者的互斥鎖內設標記，再暫停播放器。標記生效後的讀取回傳
等長靜音，不消耗PCM、音樂命令、數位音效或內插狀態，不推進獨立音樂 DOS。
恢復只清標記並繼續同一串流，維持佇列順序。主機器原始音訊錄製不加入設定期間
的合成靜音。已送往音效裝置的緩衝不算原版狀態，也不宣稱即時硬體零延遲。

## 驗收與停止線

- 狀態測試：拖曳、開啟按住、取消、套用成功、載入失敗、無效值及恢復按住。
- 串流測試：暫停反覆讀取不耗資料、不更新計數；恢復與無暫停串流逐位元組相同。
- 獨立音樂測試：有合法原版資料時核對音樂機器步數與命令佇列；缺原版明確skip。
- 正常GUI：設定前後同一原版步數的CPU、完整RAM、VGA、色盤及存檔一致；設定開啟
  期間原版步數不變；取消、Escape與套用點擊均不出現在DOS輸入收據。
- 真視窗抽驗設定列邊界、遊戲最上與最下列、失焦、按住與關窗。重播不能取代此項。
- 五語與HD後端各自達到READY並接入後，才計入對應功能完成。此規格的內部測試通過
  不代表五語、HD、完整GUI或新版本打包已完成。

2026-10-11審查：使用者已確認操作分支，現行來源足以隔離前端輸入及兩條音訊路徑。
准許依本契約實作。字型選擇、各語言排版、SS來源與HD圖層仍由目標186追蹤。
