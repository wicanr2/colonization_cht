## 原版研究與原型閘門

- 正常冷啟動、讀取既有存檔、離城，再以Colonizopedia的Terrain Types逐頁操作；
  保留實際鍵鼠輸入、暫停狀態與X11，不能以直接進入頁面取代。
- 0D46:000A的完整來源與實際目的描述子分開核對。若先解碼至16×16暫存區，
  必須保留完整返回、256次唯一不透明寫入、周圍保護區與後續搬運證據，
  不能直接沿用Main／Stage的320寬假設。
- 所有已註冊來源位址及搬運目的都追蹤未知寫入，包含同值撤銷；
  原版控制、觀測與GUI須保持CPU、完整RAM、IDX、DAC及存檔相同。
- 畫面中的地形前景與材質分開追蹤。只繪來源仍有效的4倍區塊，
  未知前景、邊框與游標保留；不從相同色號重新授予來源。
- 已觀測DAC的120至127號會循環置換，不能把單張色盤當成所有材質的固定色盤。
  第7與第11幀會使用這些色號；其餘十幀的已用色號在目前兩個正常狀態相同。
  八種循環均已正常觀測，合成契約見下節。
- 十二張生成候選先做64×64像素中心取樣、原版來源遮罩與完整畫面原型。
  原始圖、提示、參考指紋及權利記錄保留；原版參考僅留本機。

證據足以說明實際解碼、搬運、覆蓋與色盤後才審READY。正式接線另驗正常五語／兩模式、
游標進出、離頁、完整RGBA／X11、當次原版／音訊／存檔與封裝拒絕。
不從百科抽樣外推所有世界畫面、其他素材、全量HD或新版交付。

本機入口為workplace/reports/goal186-display-hd/hd-icons-remainder-r92。
capture-r92-terrain-baseline-r1.py重生正常原版路徑，
run-r92-native-terrain-r4.py重生固定當次輸入的控制及來源觀測。
首兩版因沿用R91固定收據或終點而拒絕，屬工具輸入綁定問題，沒有原版驗收信用。
