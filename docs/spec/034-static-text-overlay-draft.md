# 規格034：靜態內嵌文字覆蓋（DRAFT）

狀態：DRAFT；日期：2026-09-26。對應 [Issue #9](https://github.com/wicanr2/colonization_cht/issues/9)，候選來自[目標146 清冊](../goals/146-static-text-inventory.md)。本規格只授權可丟棄原型，不授權正式覆蓋。

## 識別條件

靜態文字沒有印字事件可當權杖，改以**畫面指紋**觸發：

- 每個覆蓋項目綁定原版圖檔 SHA-256（清冊 ST 編號）、原版索引畫面上的指紋矩形（邏輯半開座標），以及該矩形索引位元組的 SHA-256。
- 只有當幀真 VGA 索引畫面在指紋矩形內逐 byte 相符才覆蓋；任何一個像素不同（動畫影格、捲動、游標、色盤外的位移）一律不覆蓋並記錄 `fingerprint-mismatch`。
- 原版整體檔案指紋不符沿前端既有政策拒絕啟動。

## 覆蓋矩形與遮罩

- 指紋矩形可包含邊框等不應更動的像素；另設較小的**文字帶**，只在文字帶內清除原文。
- 清除方式：文字帶內屬於「文字與抗鋸齒」色號集合的像素，以同列最近的非文字像素補回，保留卷軸或底圖紋理；不以純色平塗。
- 中文以欄位專屬字級置中畫在文字帶，顏色取原版文字色（區內最暗的常見色）；畫面差異必須完全落在指紋矩形內。

## 繪製順序與失配

靜態覆蓋在動態覆蓋之前合成；同一區域若有動態事件，以動態權杖為準。指紋不符、缺譯、缺字型、文字帶超界時不覆蓋並記錄原因。
