英格蘭正常玩家路徑進入海上主畫面後的兩個區域：頂列（選單列六詞，以及回合開始時暫佔頂列的訊息）與右側狀態欄（季節年份、金錢稅率、行動點、座標、單位、命令、地形、載具內單位與貨物）。使用者 2026-09-26 決定：兩者本輪一起做；選單列寫成「(G)遊戲」，快捷鍵字母沿原版色號 149（黃）、中文色號 68（綠）；字級 22px（Cubic 11 兩倍整數縮放）；狀態欄文字加黑色陰影向右下 2 輸出像素。原版規則、數值與存檔不變；變數原值（年份、金額、百分比、座標、數量）不翻。

## 詞典與模板

[海上詞典 TSV](../../text/sea-status.zh-Hant.tsv) 共 24 列，每列綁原始檔、位移、位元組與角色（season／label／order／terrain／unit／goods／cargo／nation／nation_abbrev／port／menu）。`Gold:`、`Tax:` 取自 `LABELS.TXT @CTITLE`，狀態欄沿用同字屬**強推論**；其餘標籤、名稱均為原始檔逐字相同的片段。

執行期模板（程式 `seaTranslate`）：季節 `S N`→「N年季」、`Gold:N$  Tax: M%`→「金錢：N$　稅率：M%」、`Moves: X`→「行動：X」、`Locat: (A, B)`→「位置：(A, B)」、`縮寫. 單位`→「英．單位」、`(地形)`→「（地形）」、`N 貨物`→「N 貨物」、`國籍 單位 Inbound From 港口`→「國籍單位駛自港口」，以及命令、載具單位的整行對照。任一詞或字元缺譯時，該行保留原文並記錄於輸出 JSON 的 `sea_misses`。

## 執行期閘門與合成

前端 `-sea-status-a`／`-sea-catalog`／`-sea-atlas`。每次 `0D21:00C6` 讀字事件記錄改色像素的「第一次改寫前值」與「最後值」、點數、bbox、色號。完成的事件依位置歸類：頂列 `[0,320)×[0,8)` 的逐字事件累積成完整 39 字選單才成立，連續字串為回合訊息；狀態欄 `[240,320)×[48,200)` 的連續字串逐行成立，覆蓋同位置的舊行。每當有新行或該區底層畫布改變，就重建該區：逐行核對文字像素仍是當次改色值、改寫前值不是文字色號，否則該行保留原文；以有效行重建補片與陰影／前景遮罩（字元圖集拼字，越出安全區的行不套用）。合成時真 VGA 須在安全區等於底層畫布（游標範圍先換回底層再比對，中文畫完後把游標像素疊回）。海上兩層不佔用其他覆蓋的「已套用」旗標，遊戲選項等視窗照常蓋在上面。

字元圖集由 `tools/bake_sea_atlas.py` 以固定 Cubic 11 22～15px 八個字級（目標150 起；超界時逐級縮字，15px 仍放不下才回原文）、詞典全部中文字、模板固定字與可列印 ASCII 烘製，綁定字型與詞典雜湊。狀態欄文字列以中文墨跡頂端對齊原版墨跡頂端、左緣對齊原版左緣；回合訊息以 x=640 置中。
