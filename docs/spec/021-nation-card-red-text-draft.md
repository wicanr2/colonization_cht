# 規格021：第一張國家旗卡上下紅字

狀態：DRAFT；日期：2026-09-23。來源：[目標085](../goals/085-nation-card-text-provenance.md)、
[目標087](../goals/087-nation-card-source-load-edge.md)與[研究紀錄](../../RESEARCH-LOG.md)。
本規格只涵蓋正常玩家路徑上第一張旗卡的兩處動態紅字；不授權正式覆蓋、
其他旗卡、靜態圖像、國家選擇規則或公開散布原版素材。

兩個來源不是因字面相符而假定相同：DOS 讀取目的位址、就地整理讀寫、
解析讀寫、常駐位置及當次印字均已分別觀測。替代同文 `England`
位址 `0x21ACA` 在兩處印字窗口沒有讀取事件；共用 `0x2A74A` 在上、
下行之間被重新寫入，不能當成固定國名鍵。原版旗卡圖像可能提供底圖，
但當次紅字來自動態印字，不可將文字列為純靜態圖塊。

兩次獨立冷啟動的 DOS 載入與 RAM 事件收據各自逐位元組相同；同輸入
無觀測對照組的 CPU、完整 RAM、原版索引畫面、色盤、虛擬時間及開檔
序列一致。`tools/check_goal087_nation_flow.py` 為獨立 PASS 驗證入口；
原版 RAM、畫布、收據皆只留在已忽略的 `workplace/`。

片段：`NAMES.TXT` 原始 `England` 位於含數值的複合行，原版印字時

冒號，沒有改寫原始鍵。`LABELS.TXT` 的 `Immigration` 是完整原始行。
