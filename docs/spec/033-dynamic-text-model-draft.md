# 規格033：動態文字抽取與訊息鍵資料模型（DRAFT）

狀態：DRAFT；日期：2026-09-26。對應 [Issue #6](https://github.com/wicanr2/colonization_cht/issues/6)。本規格把已限定 CONFORMED 的各欄位（規格016～032）歸納成共同資料模型；它本身不授權任何正式覆蓋，正式行為仍只由各欄位的 READY／CONFORMED 規格驅動。

## 訊息記錄（文本鍵）

每則可覆蓋的原版文字是一筆記錄，欄位如下；缺任一欄即不得啟用。

| 欄位 | 內容 |
|---|---|
| 文本鍵 | `檔名:0x位移`（單行片段）或 `檔名:@段落`（整頁長文）；模板動態行另帶模板代號 |
| 來源雜湊 | 原始檔 SHA-256、片段 bytes SHA-256、長度；版本不符失敗即關閉 |
| 原文 | 原始檔逐字片段；執行期顯示字串另以當次讀字核對（變數展開後的值或字元序列 SHA） |
| 譯文 | 唯一 UTF-8 TSV（`text/*.zh-Hant.tsv`）的 `zh_hant`，`status=draft` 以上 |
| 輸出情境 | 讀字常式 `0D21:00C6` 的 `SS:BX` 位址型態、改色常式 `0D21:012C`、畫面區域、色號集合、印前底圖條件 |
| 輸出矩形 | 原版墨跡半開 bbox 與四倍安全矩形；中文不得越出 |
| 樣式 | 字型（Cubic 11 固定 SHA）、欄位專屬字級、前景／強調／陰影色號與位移 |
| 缺譯處理 | 保留原版畫面並記錄原因；不得靜默消失 |

## 輸出類別

1. **固定單行**：主選單、難度卡、旗卡、選項各列等。來源鍵為檔案片段；以當次讀字位址、點數、bbox 與印前底圖為權杖（規格012～023、030、031）。
2. **逐字事件列**：每字一次 `0D21:00C6` 事件（字元與 0 交錯、同基址），以整列字元序列 SHA 定鍵。開場字幕、整頁長文（介紹頁、help）、海上選單列屬此類（規格025、026、029、032）。
3. **模板動態行**：一次連續讀取的單行字串，含變數。以位置區域＋模板＋詞典鍵定鍵，變數原值不翻（規格032）。

## 替換單位與回退

- 替換單位是**整則訊息**（或整行模板），不做英文字元對中文字元的替換；原文與譯文長度不等是常態。
- 譯文由固定字型在四倍畫布排版：欄位專屬字級、欄寬內換行（禁則字）、不截斷；排版後超出安全矩形即該則回原文並記錄。
- 缺譯、重複鍵、來源不符、缺字模或圖集、字元不在圖集中：該則回原文並記錄；原版整體版本不符則拒絕啟動。
- 同文異境：同一英文字串在不同位置出現時，鍵以（類別、文字）決定，位置只作為輸出情境；同一（類別、文字）不得對到兩組鍵。

## READY 閘門

只有 READY 以上的欄位規格可以驅動正式覆蓋程式；本規格與 DRAFT 規格只能產出可丟棄原型與預覽。

## 驗證（DRAFT 所需）

`tools/text_model.py` 是本模型的獨立參考實作（不依賴 Go 前端），`tools/check_goal144_text_model.py` 以三種真實輸出情境的探針收據套用：
- 開場字幕路徑（目標141 `full`）：十張字幕與選單列共 11 組鍵全部命中，逐字事件列類。
- 首則 help 路徑（目標142 Discoverer）：`@TUTORIAL1` 命中；Discoverer 版 `@BUILD2`（`…Great Discoverer,`）未知，符合規格026的限制。
- 海上路徑（目標143）：模板動態行與選單列共 18 組鍵；`Sentry` 出現在兩個位置但只對到同一組鍵；未知只有 `-`、`S` 兩個圖示字母。
三情境都沒有同文對到多組鍵。目標143 以前的收據只記偶數位讀取，連續字串無法還原，列為未知。
