# 規格044：正式交付版號與推廣影片

狀態：CONFORMED，限版號、封包、已列平台抽樣與影片技術檢查。範圍：發行識別、三平台彙整及宣傳影片；不改原版程式、規則、存檔、翻譯鍵或覆蓋幾何。索引為[目標183](../goals/183-release-and-promo.md)。

## 版號與封包

- 使用`v.<主版>.<次版>.<修訂版>-YYYYMMDD`，日期以實際發行的Asia/Taipei日期為準。版本不得覆寫。現有`v.0.1.0-20260927`保留。
- Go1.26.7的`cmd/link/doc.go`證實`-X importpath.name=value`可設定以常數初始化的string變數。本前端新增`frontendReleaseVersion`；`--version`輸出版本、作業系統與架構，視窗標題使用同值。這是標準工具鏈契約，不是原版遊戲行為推論。
- Linux、Windows、兩個macOS切片同值；封裝前從二進位實際string符號與內容驗證，不能以檔名或任意bytes命中冒充。Linux及Wine另實際執行`--version`。
- 沿用規格041、042、043的固定時間戳、授權、原版排除與拒絕覆寫。先在各自獨立暫存根目錄封裝，再建立唯一正式版本根目錄；彙整後重新核對檔案與雜湊。
- Linux AppImage與Windows ZIP各做封包內正常啟動抽樣。macOS只驗通用檔、兩個切片、臨時簽章資料及shell接線；沒有真機與Gatekeeper驗收，不聲稱通過。
- 全部譯文已完成，尚未抽樣的畫面及保留原文的欄位列為已知限制。Issue #53的全可達依賴不得因封包存在而關閉。
- 使用者本機原版可另外組成`full-local/`自帶資料包，附一鍵啟動入口、原版指紋與私用聲明；只留本機、不提交、不上傳。公開的`patch/`仍需玩家自備原版。原版存檔不隨包複製。
- 私用包的原版檔案保留來源修改時間，其他封包檔仍固定時間戳。dosgolem `internal/dos/find.go:209`的`dosDateTime`已證實以`os.FileInfo.ModTime()`填DOS日期；驗證Python ZIP解包須依私用manifest還原時間，因該解包API不自動還原。原版日期不是可任意歸零的封包metadata。

## 2026-10-10 字模輸入恢復

狀態：CONFORMED。部分歷史字模中間物已不存在，譯文與既定字級未改。允許封裝器以 `--mask-bundle` 與 `--mask-manifest-sha256` 接受已驗正式包的完整字模集合。先核對指定 manifest 雜湊、全部13份現行譯文逐位元組相同、每個字模的 manifest 雜湊與大小、全部既有字模分類，以及兩圖集的字型與譯文綁定。任一項不同即拒絕。只沿用已授權字模，不沿用舊二進位、譯文或原版資料。新 manifest 記錄字模來源版本與 manifest 雜湊。

v.1.0.3-20261010 使用 v.1.0.2-20261005 的67個字模檔，來源 manifest SHA-256 `b5ef89cf8f894e7e01a45a5c21cd80b5df97b01459e65228d9f5169d982153e2`。新包字模逐位元組相同，三平台各兩次封裝全等，Linux／Wine正常GUI通過。錯manifest、譯文改動、字模缺失／改動／多檔及未知封裝器六個負例皆拒絕。不宣稱重新烘製字模；收據由[目標185](../goals/185-player-experience.md)索引。

## 影片

- 90秒、1920×1080、30fps、H.264與AAC；使用dosgolem正常玩家輸入重播產生的現行中文畫面，原版實際執行經既有ymfm音訊路徑錄出的音樂。沒有重作遊戲畫面或另創音樂。
- 章節卡與字幕以Cubic 11繪製，量測文字邊界；遊戲1280×800畫布完整保留，不裁切。固定畫面停留是明示的剪輯設計，不能把它當成持續遊玩錄影。
- 原始PNG、WAV、輸入與遊戲資料留在忽略工作區。來源收據記錄原版輸入、dosgolem、前端、重播、畫面與音訊SHA-256。使用者已授權此推廣影片於完整版Release公開，MP4為唯一公開原版影音衍生產物。
- 驗證時長、編碼、解析度、幀率、非靜音、黑幀、凍結與字幕邊界，抽看章節幀。凍結偵測結果須對照明示的固定畫面剪輯，不能稱為動態錄影驗收。
- FFmpeg在既有影片映像內使用2 CPU、2執行緒及veryfast；所有背景程序有trap、容器有時間與資源上限。

驗證與產物指紋見[目標183](../goals/183-release-and-promo.md)。原版行為、macOS真機及全部可達畫面不在此次完成聲明內。
