## 版號與封包

- 使用`v.<主版>.<次版>.<修訂版>-YYYYMMDD`，日期以實際發行的Asia/Taipei日期為準。版本不得覆寫。現有`v.0.1.0-20260927`保留。
- Go1.26.7的`cmd/link/doc.go`證實`-X importpath.name=value`可設定以常數初始化的string變數。本前端新增`frontendReleaseVersion`；`--version`輸出版本、作業系統與架構，視窗標題使用同值。這是標準工具鏈契約，不是原版遊戲行為推論。
- Linux、Windows、兩個macOS切片同值；封裝前從二進位實際string符號與內容驗證，不能以檔名或任意bytes命中冒充。Linux及Wine另實際執行`--version`。
- 沿用規格041、042、043的固定時間戳、授權、原版排除與拒絕覆寫。先在各自獨立暫存根目錄封裝，再建立唯一正式版本根目錄；彙整後重新核對檔案與雜湊。
- Linux AppImage與Windows ZIP各做封包內正常啟動抽樣。macOS只驗通用檔、兩個切片、臨時簽章資料及shell接線；沒有真機與Gatekeeper驗收，不聲稱通過。
- 全部譯文已完成，尚未抽樣的畫面及保留原文的欄位列為已知限制。Issue #53的全可達依賴不得因封包存在而關閉。
- 使用者本機原版可另外組成`full-local/`自帶資料包，附一鍵啟動入口、原版指紋與私用聲明；只留本機、不提交、不上傳。公開的`patch/`仍需玩家自備原版。原版存檔不隨包複製。
- 私用包的原版檔案保留來源修改時間，其他封包檔仍固定時間戳。dosgolem `internal/dos/find.go:209`的`dosDateTime`已證實以`os.FileInfo.ModTime()`填DOS日期；驗證Python ZIP解包須依私用manifest還原時間，因該解包API不自動還原。原版日期不是可任意歸零的封包metadata。
