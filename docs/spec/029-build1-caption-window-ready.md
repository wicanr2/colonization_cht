# 規格029：首張開場字幕的限定輸出覆蓋（CONFORMED）

狀態：限定 CONFORMED；READY 證據審查與正式視窗同狀態驗收：2026-09-25。這是[規格026（DRAFT）](026-build-intro-and-tutorial-prefetch-draft.md)的**單一字幕窄切片**，不是整組 `@BUILD1–10` 或 help 的升級。

## 玩家可見範圍與權利

只在固定 DOS 版《Sid Meier's Colonization》、英格蘭正常玩家路徑的第一張 `@BUILD1` 開場字幕，把原版單行英文字覆蓋成主譯稿 `GAME.TXT:0x000153CC` 的繁體中文，保留原版淡黃前景與暗影。原版執行、規則、存檔、輸入、RAM 與全部資產不變；其他字幕、教學、國家或選項視窗不由本規格授權。字型原檔、原版像素／完整收據及混有原版像素的截圖只留已忽略的 `workplace/`；不得加入 Git 或公開發行。

## 固定輸入、位址與證據審查

- 原版輸入由現有前端的 `OPENING.EXE`、`VICEROY.EXE`、`GAME.TXT`、`LABELS.TXT`、`NAMES.TXT` 各 SHA-256 失敗即拒絕啟動。`GAME.TXT` SHA-256 `67a6b5e22d1addc1ae13658d0d7824622f6d21c6c2bfdefc91f9749450cc2e3a`；檔案位移 `0x153CC` 的63 byte含兩個 `^` 控制碼，可見正文始於 `0x153CE`，61 byte SHA-256 `c1feca9ed16dd6cf8cfd36a118536afd25b86f6677f3ec81d056fad6e78a6db6`。原文與譯文只從 UTF-8 TSV 鍵讀取；程式不內嵌譯文。
- 原版實模式 `0D21:00C6` 的122筆讀取逐一由 `SS:BX` 指向20-bit線性 RAM `0x2A560/1`，可見61 byte與交錯零位完全匹配；`0D21:012C` 在原版320×200底層畫布線性 `0x2CAE0` 以後改色1,040點，半開墨跡框`[16,30,303,39)`。第一筆讀取及第一筆畫布寫入前的底圖皆為 SHA-256 `d8d0d8e5de5655411fd4935d2b96e6e84845ee924658668f9486196ede9882ab`。以上當次讀字、運算元、畫布寫入與原版像素為**已證實**；`GAME.TXT` 讀入目的至最後印字緩衝的每一步搬運仍是**強推論**，本規格不憑該邊決定顯示鍵。
- 原版畫布印後 SHA-256 `b8c0d43983c95415071e83513628fc90e8de3236f3e75eb699ed4d87dfc8c772`，當次 VGA DAC SHA-256 `92593125369b8224c1f00b30ad0367d6f1766da49afb614dcf753ad8d70b665b`。dosgolem `Machine.Indexed()` 是實際 VGA 影像拷貝，不是滑鼠合成層；原版底層畫布已完成後，實際 VGA 文字安全區仍有6個畫格不同。**已證實**固定路徑第538–543幀／88,770,000–89,595,000步不可覆蓋；第544幀／89,760,000步實際 VGA 與底圖首次同狀態，連續641個畫格到第1184幀；第1185幀／195,525,000步換頁失效。不能把第538幀的底圖完成誤稱可見畫面完成。
- [目標130](../goals/130-build1-ready-and-ebitengine-overlay.md)的 dosgolem 原版雙冷啟動報告逐 byte 同 SHA-256 `f0bc1a1747c5086bd1598ec39a6eca4490b44bb6d4b6dcc17e6d6a6bacd647dc`；無讀寫監看控制 `ab8afb27ac6a94062c5346bc621315c9f7ce6d95aff5b817be7a85ffda7afa41`。34個正常玩家取樣的 CPU、完整 RAM、索引與底層畫布、色盤、模擬時間及開檔一致；`tools/check_goal130_caption_screen.py` 的正例與 `tools/test_goal130_caption_screen.py` 的18項篡改／回退負例、缺合法原版 `SKIP 77`通過。工具為隔離 dosgolem `9dd36726eeaf9c1f3a745aabdcbb84413791d90f`、`colonization-research:20260920-r2`／Go 1.24.13。上述步數是此版本模擬指令數，不作其他版本或真實時鐘契約。

## 欄位版面與資料契約

使用者已選 A：固定 `Cubic_11.ttf` SHA-256 `8de9c249b92bc414cb73f09ddb76c7cb327edb3907b638f0d0bd22691237fd5c`，字級38px、中文字模墨跡430×35px，原版字高9邏輯像素約36px。原版單行墨跡與周圍圖案給出邏輯安全區`[12,27,307,42)`；四倍畫布`[48,108,1228,168)`。中文前景半開框`[423,120,853,155)`、暗影`[427,124,857,159)`，兩者均在安全區；前景取當幀 VGA 色號14、暗影47。此欄不換行、不截斷、不縮字；TSV 譯文去除 `^^` 後的真字模若非430×35、缺字或超界，顯示完整原文並記錄原因。此38px決定不能外推其他字幕或遊戲選項九欄。

字模 JSON 只在本機由現行 TSV 與固定 TTF 烘製；正式前端在啟用前比對候選鍵、譯文雜湊、字型雜湊、38px、430×35尺寸、Alpha長度及兩個實際墨跡框。譯稿缺鍵、重複鍵、來源位移／bytes／雜湊不符或控制碼錯誤，逐欄停用中文字幕，保留原版；原版整體版本錯誤則沿前端既有失敗即關閉政策拒絕啟動，不猜測套用。

## 執行期狀態機與失敗模式

1. `idle`：只有使用明示 `-build1-a` 且上述檔案指紋有效才安裝觀測。於原版 `0D21:00C6`、`SS:BX` 線性`0x2A560`讀出本行首字元，且底層畫布符合已驗印前 SHA、mode13h 時，捕捉唯讀底圖，進入 `reading`。其他相同英文字串、預讀或只憑畫面雜湊不得建立權杖。
2. `reading`：逐次核對 61個正文 byte和交錯零位的122筆 `SS:BX` 讀取，並核對同一期間 `0D21:012C` 對底層畫布的1,040筆改色、位置框與原版色號。任何錯值、越界、插入另一印字串、改色來源不符或未完成即撤銷並留原文；不得改原版 RAM。
3. `waiting-screen`：讀字完成後底層畫布、mode13h及當幀色盤須保持上述指紋；在最多2,000,000模擬指令內等待實際 `Machine.Indexed()` 等於印後 SHA。早期6幀即使底圖完成，實際 VGA 未同狀態也保留原文；逾時或底圖／色盤先換頁即撤銷。2,000,000是本翻譯層保守上限，不宣稱原版時序常數。
4. `active`：用**當次**捕捉的印前底圖與當前完整原版印後畫布建立 `overlay.Patch`；每幀原版底圖、實際 VGA、色盤、模式及資料／字模綁定仍匹配才在四倍安全區恢復原始多色背景，畫色號47暗影和14前景。鼠標16×16佔用框與中譯實際前景／暗影所及的邏輯`[105,30,215,40)`相交，或滑鼠按鈕仍按下時，本幀保留原文；不以更寬的背景安全區阻擋無關移鼠。若實際 VGA 暫時不同，同樣保留原文；底圖、色盤、模式或頁面變化則權杖永久失效，不在日後相同畫面復活。前端不攔玩家輸入或影響原版狀態。
5. `expired`：不保留圖層、不可重用舊印前背景；只有新的完整當次印字事件及正確印前底圖才能再開新權杖。獨立 dosgolem 原版探針路徑在88,689,021步有另一筆當次印字；真 Ebitengine 錄製路徑則在78,889,224步印字，兩者是不同輸入路徑，不得混稱同一次頁面重印。缺譯／缺字模、格式錯誤、任一條件不符時顯示原文並記錄明確原因。對錯版原版採拒絕啟動，不執行未證實位址。

上述狀態是輸出層的安全策略；已證實的是原版事件與固定正常玩家相位，2M逾時與全畫面哈希是保守**設計選擇**，不冒稱原版內部規則。沒有新遊戲資料格式或存檔影響。

## CONFORMED 驗收收據與邊界

- 真 Ebitengine 視窗錄得的同一真視窗收據的前24／25筆原版輸入在82M字幕中、86M及120M各自冷啟動中／英文控制，CPU、完整 RAM、索引 VGA、DAC 色盤、Ticks／Frames／Cycles、開檔及輸入一致；82M中字畫面只在安全區改像素，120M的PNG逐 byte與英文控制相同。82M 當次 `0D21:00C6` 來源事件在78,889,224步，經1,040點改色後80,190,001步首次套用；真 VGA 未同步前七個畫格全保留英文。這些步數屬**真視窗錄製路徑**，不和上節獨立探針路徑混用。
- 固定38px字模實際430×35px；印前多色底圖恢復、色號47暗影及14前景由獨立 Pillow 重建。安全區外、空白與實心墨跡逐像素相同；Pillow 與 Go `image/draw` 的858個抗鋸齒邊緣像素最多差2色階，屬驗證器跨繪圖庫捨入，正式PNG仍由 Go 原樣輸出。`tools/check_goal130_window.py` 本機摘要 SHA-256 `1344a244196abf1fd304a3a57111c628876dfb71bc33f6563a21e154e6e061ce`；十七欄既有圖層與29個事件前727幀逐筆等於先前真視窗收據。
- 缺字模、缺譯文、重複TSV鍵，以及明示合成游標壓到中譯墨跡，均經正式視窗同輸入英文控制驗證回退；最後游標守門版在正常82M畫面及原版狀態與已驗A版逐 byte相同。`tools/test_goal130_window.py` 的七項篡改拒絕，原版探針的18項來源／畫布／色盤／模式等拒絕、缺合法原版 `SKIP 77`皆通過。錯版仍沿正式前端原有 SHA 前置閘門拒絕啟動。測試游標是由真錄製前綴額外插入一筆明示事件的負例，不冒稱真玩家輸入收據。
- 除上述錄製輸入的合成重播外，`tools/probe_goal130_window.sh` 另以 `xdotool` 真鍵鼠從冷啟動走到實際開啟的 Ebitengine 視窗，在84M擷取1280×800玩家可見畫面；25筆當場輸入收據 SHA-256 `df5b4cedd480b9569676c5174237005c0d0eebb6c37004f6c8189239a9fbe878`，現場 PNG SHA-256 `4f3a959a770e087ba532fbdb8d15fb1a983ce9e11162bd8e3fe7f770145013b3`。這張現場圖與已驗82M中文字幕重播PNG逐像素一致，視窗終點仍套用字幕。兩組輸入步數不同，不把完整遊戲狀態跨組誤稱同狀態；本機現場圖仍不入 Git。
- 本限定規格只證明固定原版英格蘭首張字幕、明示 `-build1-a` 且本機字模正確時的正式輸出。其餘九張字幕、help、遊戲選項九欄、其他國家、發行包及整體中文化仍另驗，不因本規格完成而宣稱全文完成。

## 撤銷條件（目標141 起的現行版本）

字幕權杖只在底層畫布、色盤、mode13h 改變時撤銷，開檔不再列為撤銷條件：`@BUILD1` 顯示期間原版會在背景預載 `PHYS0.SS`／`ICONS.SS`／`BUILDING.SS`，畫面不變。無額外按鍵的英格蘭路徑上，`@BUILD1` 中文從 80,190,001 步持續到換頁；每幀仍須真 VGA 等於印後 SHA 才套用。此版本的驗收見[規格026](026-build-intro-and-tutorial-prefetch-draft.md)目標141一節。上文「86M」收據屬舊版（開檔即撤銷）前端。
