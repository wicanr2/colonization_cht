## 設計

1. **偵測：**`0D21:00C6` 讀取且讀取位址等於 `SS:BX`、影像模式 13h 時，若位址等於目前一串的下一位址且距上次讀取不到 200,000 步，併入目前一串；否則丟棄未完成的一串，從此位址開始新的一串。讀到 0 即完成。
2. **像素歸屬：**一串開始後、完成前，`0D21:012C` 的寫入都屬於這一串的最後一個字：記下每點第一次改寫前的值與最後值、逐字墨跡範圍與色號。其他寫入者落在該串墨跡外擴 1 邏輯像素範圍內時，該串回原文。
3. **篩選與分工：**至少兩個英文字母、有墨跡、單一色號。多色字串（例如木刻畫標題牌）回原文並記錄 `multi-color`。規格032 海上層啟用時，墨跡落在其頂列或狀態欄、且海上層詞典與模板能翻的字串歸海上層。已由專屬欄位處理的原文（對話框引擎排除的譯稿鍵、旗卡片段表全部列）不處理，比對時去頭尾空白，也比對去掉一層外括號後的原文（原版會在片段外加括號印出，例如 `(Click Here When Finished)`），記錄 `owned-by-field`。
4. **比對：**
   - 模板表 `text/string-templates.zh-Hant.tsv`：原文樣式與中文樣式，槽位 `{n}`（十進位數字，可含 `,`）、`{w}`（字典中的一個片段，譯為其中文）、`{colony}`（殖民地名稱）。其餘字元逐字相同，空白數也要相同。必須恰好一列命中。
   - 字典：規格032 海上詞典、譯稿 `text/draft.zh-Hant.tsv` 與語料清冊中 LABELS.TXT、NAMES.TXT、WOODCUT.TXT、MENU.TXT、GAME.TXT 的單行列（不含 `~`、`#`、`@`、`^` 控制碼）、定稿術語表。去除尾端空白後與原文整串相同即命中；同一原文有兩個不同中文視為查無。
   - 模板沒中時，整串查字典。
   - **殖民地名稱**（使用者 2026-09-28 決定）：等於 COLONY.TXT 預設名時顯示「中文（原名）」，中文取 `text/colony-bilingual.tsv` 的中文名稱部分；其他名稱是玩家資料，保持原樣。
   - 任何槽位或整串查不到就回原文，記錄於輸出 JSON 的 `string_misses`。
5. **字級：**起始字級為 ⌊原版大寫字高 × 4.4⌋ px（字高 5 得 22px，與規格032 使用者選定相同；字高 7 得 30px，與規格035 相同），寬度放不下時逐級縮到 ⌈起始 × 2/3⌉，仍放不下回原文。
6. **安全區與版面：**安全區為原版墨跡外擴 1 邏輯像素（畫面邊界內）。中文單行，靠原版墨跡左緣，中文墨跡頂端對齊原版墨跡頂端；字色取原版色號，不加陰影。擦字以印前值還原本串文字像素。規格032 海上層啟用時，墨跡落在狀態欄 `[240,320)×[48,200)` 的字串沿用規格032 樣式：黑色陰影向右下 2 輸出像素，安全區可向右延伸到欄右緣，但只延伸到中文實際需要的寬度（避免把之後才畫的圖示納入比對）。
7. **生命週期：**完成時記下安全區畫布；等真 VGA 在安全區與它相同才啟用，2,000,000 步內未啟用或畫布先變即撤銷。啟用後安全區畫布與完成時不同則暫停；之後回到完成時的內容即恢復（對應原版整塊還原畫面而不重印）。比對都略過游標範圍（游標常式也寫入本畫布）。新一串的原版墨跡與舊串原版墨跡重疊（同位置重印）、影像模式改變，舊串即撤銷；相鄰行安全區相接不算。最多保留 512 串，超過先撤銷最舊者。按住滑鼠時整層回原文。
8. **分層：**本層在所有覆蓋之後繪製；對話框（規格035／036）啟用時，與其安全區重疊的字串不繪製；游標像素最後疊回。
