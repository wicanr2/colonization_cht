## 設計

1. **偵測：**`0D21:00C6` 讀取且讀取位址等於 `SS:BX`、影像模式 13h 時，若位址等於目前一串的下一位址且距上次讀取不到 200,000 步，併入目前一串；否則丟棄未完成的一串，從此位址開始新的一串。讀到 0 即完成。
2. **像素歸屬：**一串開始後、完成前，`0D21:012C` 的寫入都屬於這一串的最後一個字：記下每點第一次改寫前的值與最後值、逐字墨跡範圍與色號。其他寫入者落在該串墨跡外擴 1 邏輯像素範圍內時，該串回原文。
3. **篩選與分工：**至少兩個英文字母、有墨跡、單一色號。多色字串（例如木刻畫標題牌）回原文並記錄 `multi-color`。規格032 海上層啟用時，墨跡落在其頂列或狀態欄、且海上層詞典與模板能翻的字串歸海上層。已由專屬欄位處理的原文（對話框引擎排除的譯稿鍵、旗卡片段表全部列）不處理，比對時去頭尾空白，也比對去掉一層外括號後的原文（原版會在片段外加括號印出，例如 `(Click Here When Finished)`），記錄 `owned-by-field`。
4. **比對：**
   - 模板表 `text/string-templates.zh-Hant.tsv`：原文樣式與中文樣式，槽位 `{n}`（十進位數字，可含 `,`）、`{w}`（字典中的一個片段，譯為其中文）、`{colony}`（殖民地名稱）。其餘字元逐字相同，空白數也要相同。必須恰好一列命中。

5. **字級：**起始字級為 ⌊原版大寫字高 × 4.4⌋ px（字高 5 得 22px，與規格032 使用者選定相同；字高 7 得 30px，與規格035 相同），寬度放不下時逐級縮到 ⌈起始 × 2/3⌉，仍放不下回原文。
