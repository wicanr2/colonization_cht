# 規格015：難度頁完成提示輸出覆蓋

狀態：CONFORMED（僅難度頁完成提示）；日期：2026-09-22。入口：[目標062](../goals/062-difficulty-finish-prompt.md)。

## 問題與輸入

難度頁的 `Click Here When Finished` 目前仍為英文。固定合法 DOS 版的
`LABELS.TXT` SHA-256 為
`e4af0da201eb4df5ecdc2033d711d30f975c752f2967dc97b6a8159004582204`；
檔案位元組位移 `0x86E` 的 24-byte 原文對應唯一 TSV 候選
`LABELS.TXT:0x0000086E`，繁中草稿「完成後點此」。原始檔下一 byte 是 CR；
執行期線性 `0x4DF59` 的 24-byte 原文後接 NUL。檔案至記憶體的完整載入器
資料流未追畢，故檔案位移仍標為候選，不單獨用於覆蓋。

## 研究證據

`tools/probe_difficulty_writes.go` 在隔離 dosgolem 提交
`9dd36726eeaf9c1f3a745aabdcbb84413791d90f`、研究映像
`colonization-research:20260920-r2` 中，按 `goal059-ebiten.inputs.json`
從 `OPENING.EXE -g` 正常冷啟動，兩次獨立重播的讀寫事件、七個畫布／索引
檢查點及最終 RAM 雜湊一致。原始輸入 `OPENING.EXE`、`VICEROY.EXE`、
`GAME.TXT`、`LABELS.TXT` 的 SHA-256 由探針固定檢查。

位址基準：`0x4DF59` 是 DOS 20-bit 線性記憶體；`0E2D:11CF`／`0E2D:11E7`／
`0E2D:11EB`／`0D21:012C` 是 DOS 實模式 `CS:IP`；bbox 是 320×200 畫布
邏輯像素。這些數值不是檔案位移或 IDA 地址。

- confirmed：步 29,779,574，`0E2D:11CF` 讀線性 `0x4DF59..0x4DF71`；
  `0E2D:11E7`／`11EB` 隨後讀同一來源。`0D21:012C` 於
  29,780,831..29,790,545 步在提示區寫出 167 個變更像素，bbox
  (13,81)–(101,85)，變更後色號全為 254。
- confirmed：`finish-before` 與 `finish-after` **全畫布**差異恰為這 167 點，
  全數落在候選安全矩形 (10,79)–(105,88)（右／下不含）；至 `settled`
  畫面該矩形零變更。兩次重播的檢查點與最終 RAM 指紋相同。

## 限定覆蓋契約

只在上述固定版本、`DIFFICUL.PIK` 已開啟、原文與 NUL 完全相符，且
`0E2D:11CF` 真實讀取該來源時保存原始畫布。待原版文字繪製完畢，
若安全矩形的差分精確符合 167 點、bbox 與色號 254，才用既有純合成器
建立可逆背景補片。中文只從唯一 TSV 取得，Cubic 11 24px 字模僅在本機
生成；需驗證字模雙軸完整落在 4 倍安全矩形。版本、來源、畫面、字模、
游標或切場不符均顯示原文並記錄原因。

READY 審查須複核此讀取／畫布序列不是早先標題的附帶動作，確認中文安全矩形
不碰難度卡片或互動區；其後以正常玩家輸入做中英同狀態及真視窗逐像素驗收。
本規格不授權其他出現相同英文的畫面、卡片標籤、help、遊戲規則或存檔變更。

## READY 審查

主代理複核兩次 `goal061-difficulty-writes{,-replay}.json` 與原版前後畫布：
標題兩行的首字讀取為 `0D3A:0015`、後續字串讀取為 `0E2D:1194`，
而本提示於其後才從 `0E2D:11CF` 讀取線性 `0x4DF59`，後接另一段
`0D21:012C` 畫布寫入；因此不是標題事件的附帶像素。完整 167 點差分
均在 (10,79)–(105,88)，與右側卡片畫面區分離。原版圖可見滑鼠仍採
原有按鈕命中區；覆蓋僅改 RGBA 輸出，不改 DOS 滑鼠或原版畫布。

已確認的 Cubic 11 24px 對「完成後點此」量得 bbox (0,2)–(130,24)，
字模 130×22；置於放大畫布 (52,324) 時完整位於安全矩形
(40,316)–(420,352)。單行顯示，不換行、不裁切；譯文增長超界時回退英文。
版本、來源、事件、差分、字模與每幀背景守門均可用既有原型機制表達，
不需要猜原版規則。故只將此提示升為 READY 並進入限定實作；以下驗收通過後，
才將本提示標為 CONFORMED。
