## 研究入口與待驗契約

[海洋繪製探針](../../tools/probe_hd_terrain_draws.go)從原版OPENING.EXE冷啟動，
重播既有正常GUI輸入與初始COLONY09.SAV，不注入玩家狀態。
初始存檔SHA-256為52ae8b7bd4bea1869afb825af165a8edc50882fc176d49985d4fb3c362d5469b，
輸入收據為9b246ee6e4aa2fc36e3db4eae8fa8487527e7b4393afff9fdcfe19e61c741979。
工具僅讀記憶體及觀測寫入，不由正式組裝器引用。
[來源鏈檢查器](../../tools/check_hd_terrain_draws.py)另核對原始收據、逐點來源及既有定位，
不把探針的成功訊息當作驗收。

- 先查原版0D46:000A是否使用本完整編碼來源。入口與原始記錄位移運算沿
  [規格061的IDA證據](061-hd-building-draw-lifecycle.md)，不先外推建築幾何或幀號。
- 記錄來源遠指標、暫存器、堆疊、目的描述、入口與返回；本工具只接受完整16×16未裁切樣本。
- 核對每次實際寫入、原版返回圖像及後畫遮擋，包含同值寫入。
- 與不安裝觀測器的相同輸入重播比較世界及進城檢查點的完整RAM、CPU、VGA與DAC。
- 實際繪製入口、裁切、重畫、動畫、游標、岸線與其他地形交疊仍須逐項確認。

首輪唯讀重播已證實293次完整來源命中，目的描述皆為`[200,320,0,3C50h]`。
這是線性RAM `0x3C500`的暫存畫布，與首座建築的`0x2CAE0`不同。
首輪嚴格沿建築畫布檢查，因此沒有選取繪製樣本；保留該收據，不當成產品錯誤。
接續觀測暫存畫布的完整寫入、返回及主畫布轉送，未猜測兩側座標對應。


## 2026-10-12來源至主畫布的限定證據

confirmed限既有正常玩家輸入重播至75900000步。工具為Go1.26.7、Python3.11.2、
Pillow9.4.0與隔離dosgolem `82a14b266e1b5bc904e2d0fe507daf6bea41a013`。
原版、正式前端及dosgolem未改。本次沒有新增HD正常GUI收據。

| 原始定位 | 實際觀測 |
| --- | --- |
| 原版0D46:000A | 入口12bytes為`c828000052535057568b4702`，完整來源命中293次，皆未裁切。 |
| 原版RAM 4F22:0732 | 原始words為`[15,21752,304,89,16,16]`，來源54F8:000F，完整263bytes與PHYS0.SS一致。304、89不賦予用途。 |
| 入口AX、DX與SS:SP+4 | 本素材AX149；DX及堆疊讀值與實際16×16寫入位置一致。幀號關係只限本素材。 |
| 目的描述原始words | `[200,320,0,15440]`，即3C50:0000、線性RAM0x3C500，不等於主畫布。 |
| 原版0D46:01B4／01D2 | 每次分別寫68／188點，共256點各一次；返回像素與完整來源相同。 |
| 原版返回121D:1554 | 293次皆在100000步內且SP增10返回，首筆55030152至55035075步。 |
| 原版0CBA:00CA | 原始16bytes為`f3a503f3790c81ee00808cd981c10008`，實際REP MOVSW將來源送到主畫布。 |

以上記錄位置、遠指標與CS:IP皆為dosgolem執行期定位，不是IDA EA。
入口及記錄讀取公式的既有IDA出處沿規格061；本輪沒有新增IDA資料庫或推測改名。
每次256點按局部位移排序，以uint16小端位移加色號編碼，768bytes指紋為
`f81941f19ff0b50933f8520099d8e8c74b2a1d31563521c53df5e7eeb0736da3`。

複製來源逐byte依本次DS:SI、ES:DI及目的地址差取得，word內兩個byte均核對原始色號。
只有仍保有已驗來源身分的點可傳遞；任何後畫均撤銷，包含同值寫入。
本路徑共69896個已驗來源像素轉送。

| 檢查點 | 主畫布仍可追溯的海洋 |
| --- | --- |
| 世界63525000步 | 131次繪製、32867點；108個完整256點、2個128點、14個241點及7個227點。 |
| 進城75900000步 | 0點；暫存畫布仍有16852點，不能因此將海洋畫到城內。 |

世界仍可見的32867點均與主畫布及VGA索引相同，座標差皆為`(0,+8)`。
108個完整矩形與先前完整像素定位逐項相同。部分遮擋的具體素材類型仍未逐項定義，
不由像素相似度恢復已失效身分。暫存畫布有41432筆同值撤銷，不能靠終點顏色相同判定沒被覆蓋。
游標0B68:051C的512點後畫照常撤銷；本輪尚未驗該路徑的還原配對。

觀測、無觀測兩側的兩個檢查點完整RAM、CPU暫存器、VGA與DAC一致，
主畫布及暫存畫布逐byte相同。八種錯誤證據全拒絕，缺原版回SKIP及77，
錯來源像素在建立輸出前拒絕。未比較WAV、音樂、人耳同步或即時效能。

完整提示、工具、參考雜湊與生成圖雜湊存於各自JSON。v2只降低對比與紋理密度。

`27deaccd2785a85d5ba45c462ee7ca47d160ec48683b291b379573fded5f9674`。
生成原圖與含原版像素的對照均未加入Git，未定正式素材。

只替換525872個放大後像素，遮罩外逐像素保持原版。

已目視3×3重複及實際地圖；接縫距離僅作量測，不當作美術通過門檻。
海洋與尚未重繪的岸線色調、游標還原、動畫及即時HD仍待正常玩家路徑驗證。

  hr-go-ebiten:1.26.7-2.9.9-r1，不在主機執行探針。
