狀態：DRAFT。與正式程式隔離的可丟棄原型，不加入發行包。

入口：[目標186](../goals/186-display-settings-and-gameplay-video.md)，

## 本次要查證的玩家路徑

在真正的dosgolem／Ebitengine視窗增加48px畫面外設定列，遊戲區維持1280×800。
由正常鍵鼠開啟設定，核對原版步數、CPU、完整RAM、VGA與DAC在暫停及套用時不變。
取消或套用後等實體鍵與滑鼠全部放開再恢復；設定按鍵不進DOS輸入收據。

先驗既有繁中與原版英文的即時顯示切換。原版來源觀測持續工作，英文只停止中文
顯示合成，不重啟DOS、不送假按鍵、不要求原版重畫。切回繁中從目前原版畫面合成。
其他語言與HD選項可用於驗證載入失敗保留，但未有完整資料包時不得套用或聲稱支援。

## 原型來源與邊界

- 原始核心檔、SHA-256、工具版本及地址空間沿規格050、目標186與RESEARCH-LOG。
- 組裝器先核對正式適配器與視窗檔SHA-256，複製到新的workplace建置目錄，僅修改
  該副本；正式`live_menu.go`、`window_prototype.go`與發布版保持原樣。
- 設定介面文案使用UTF-8 TSV，五個語言欄都有文案。這只是前端介面譯文，不是
  五種遊戲譯文包。重複key、欄數、缺欄及缺字均在開窗前拒絕。
- 介面暫用已展示的Noto Sans CJK候選作輸入查證。固定TTC SHA-256為
  `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`，
  來源及OFL見目標186。這不代替使用者尚待回答的遊戲字型選擇。
- 原型內的設定列、面板與文字安全矩形獨立於原版遊戲區。各欄用真實字型量測
  墨跡與兩軸邊界，最長五語文案須通過；不靠繪圖裁切遮住超界。
- 設定動作另存本機收據，記錄原版狀態指紋與DOS輸入數。原始圖像、TTC與收據
  不加入Git。未驗證GUI、原版同狀態及字型決定前不升READY、不進正式啟動器。

## 驗收

1. 正常冷啟動、載入合法存檔，進世界與殖民地；原版輸入不注入狀態。
2. 開設定後按住、移動、等待，原版步數及狀態不變；取消、Escape及套用不穿透。
3. 繁中→英文→繁中立即重合成，原版狀態不變、舊語言沒有殘留。
4. 未安裝語言與HD套用失敗，保留目前顯示及設定面板。
5. 視窗最上、最下列與工具列座標正確；失焦與拖曳不造成設定誤開。
6. 正常GUI的DOS輸入交給正式前端與原文控制重播，核對完整原版狀態與存檔。
