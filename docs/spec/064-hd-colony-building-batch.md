# 城內十種建築的HD來源擴充

狀態：DRAFT。僅授權唯讀研究，不授權正式HD覆蓋。

## 範圍與入口

接續[目標186](../goals/186-display-settings-and-gameplay-video.md)已確認的畫風與顯示替換方式。
首座建築、海洋與人物的限定CONFORMED不變。
本批研究正常殖民地畫面已完整匹配的BUILDING.SS第016、021、024、027、035、039、
042、043、044及045幀。不推定建築名稱、升級規則、動畫或其他場景。

研究入口為[批次繪製探針](../../tools/probe_hd_building_batch.go)及
[獨立來源檢查器](../../tools/check_hd_building_batch.py)。
本機證據根為workplace/reports/goal186-display-hd/hd-building-batch-r39，
prepare-source.py以固定mpskit解碼器重生來源；commands-r39.json保存實際容器命令。
解碼像素、原版參考、寫入事件與存檔均只留本機。

  通過僅證明本批來源與正常路徑，不代表HD、直接懸停或遮擋還原完成。
