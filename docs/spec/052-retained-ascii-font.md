# 非英文模式保留英數的高清字型

狀態：CONFORMED，限定已驗單色主畫布英數。入口：[目標186](../goals/186-display-settings-and-gameplay-video.md)。
本節授權依下列契約接入正式前端；未驗樣式及全遊戲完成度仍保留限制。

## 已確認需求與根因

使用者要求非英文模式保留的英文字與數字使用該語言字型，英文使用原版字體。
目前先沿用已發布繁中版的Cubic11，不代替尚待決定的新遊戲字型。

confirmed程式定位：`stringRuntime.finish`在文字沒有兩個英文字母時直接返回；
`stringCatalog.translate`無譯文回`no-template`，消費端不建立顯示項。
這兩個條件使純數字及部分保留原文使用原版點陣。字型圖集已有英數，仍須接入
原版印字事件，圖集含字不能當作英數覆蓋完成。

原版印字來源、字元墨跡writer、畫布及生命週期沿[規格038](038-string-overlay-draft.md)。
本輪來源為原版CS:IP `0D21:00C6`及glyph writer `0D21:012C`；來源指標使用
20bit執行時線性RAM，矩形使用320×200邏輯畫布，均非EXE檔案位移。
VICEROY.EXE與遊戲文字指紋沿`docs/text-census-baseline.json`，固定dosgolem82a14b2。

## 候選邊界

- 既有翻譯成功者維持既有路徑。只考慮完整印字事件中的可列印ASCII，至少有一個
  字母或數字。原始值直接來自當次印字事件，不複製英文字串或數值進程式。
- 保留原因與缺譯紀錄分開；保留原文換字型不增加翻譯或shown完成數。
- 第一個候選只處理主畫布、單色、無描邊、無熱鍵分色、沒有其他writer的字串。
  已由專屬欄位處理、來源混合或語意歧義者不接手。離屏標籤及多色樣式待另驗。
- 每次記錄讀字入口的ES:DI，包含結尾0。ES須為主畫布段`0x2CAE`，
  相鄰游標須在同列，advance介於1至32邏輯像素，當字墨跡須完整落在該字格內。
  缺游標、換段、換列、倒退、過寬或墨跡超出字格均回原版，記錄原因。
- 排版矩形由原版墨跡左上角至末字實際advance右界，高度沿原版墨跡。
  安全區為此矩形外擴一點。候選使用既有指紋及譯文綁定的圖集，量測每個
  真實字形的alpha墨跡及advance。在12至30px中選能完整放入排版矩形、
  墨跡高度最接近原版四倍的一個；同高度時選較大字級。字形上緣與左緣
  對齊原版墨跡，不沿用CJK墨跡頂端，不以「1」的墨跡寬度代替字格寬度。
- 不清整列、不超出當次字格、不截字。缺字或放不下時保持原版，記錄原因。
  印前背景、重印背景及VGA同步沿規格038。新英數項只有active且真VGA安全區
  完整吻合時才畫；不使用既有中文的三成墨跡部分遮擋規則，也不套用海上
  舊字殘影清除。游標仍由既有獨立層處理，原版恢復完整區域後可恢復英數。
- 英文原文控制不啟用候選。不寫原版RAM、VGA、DAC、存檔、來源檔或輸入佇列。

## 證據與驗收

以合法COLONY09及已驗正常GUI輸入觀測世界、城市、建造、購買與存檔。
保存每次來源、步數、字元矩形、色號、原有拒絕原因、候選字級與墨跡邊界。
有無觀測須有相同完整原版狀態。原始文字、圖像及收據只留workplace。

候選先檢查真字型、缺字、超界、來源／樣式守門與不修改輸入，再以正常GUI
驗證數量、貨幣、括號、百分比、保留英文及改值後撤銷。完整輸入由原文控制
重播，比對CPU、RAM、時鐘、VGA、DAC、音訊與存檔；可見差異只准在已驗安全區。
審查後才升READY，正式新GUI及重播通過後才限定CONFORMED。

未知：其他印字入口、單字母熱鍵、離屏標籤、多色、輸入游標、所有畫面的英數覆蓋。
本規格不以一條數字路徑代表全遊戲英數已完成。
